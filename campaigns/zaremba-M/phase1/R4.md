# R4: automorphic input for the moving two-parameter measure

Task 006; 2026-09-26. Internal research report. Ordinary route audit, not a clean-room attack. No claim of a new Zaremba theorem, no priority claim, and no kernel formalization. This report uses the task's phase-0 context, exact elementary arguments, bounded finite computations, and the primary sources identified below. No other phase-1 exploration report was used as mathematical input. The coordinator confirmed the determinant/sign convention while this report was being completed.

**Conclusion.** The proposed substitution of a lattice spectral gap for Bourgain–Gamburd is not completed. No positive numerical Corollary-16 exponent is certified by the R4 argument audited here. The needed additional theorem is a uniform *weighted word-distribution* estimate, stated in §4. Published fixed-group expansion and orbital-counting statements examined below do not supply that estimate with the required moving parameters and constants. However, the phase-0 thinness diagnostic does **not** kill the route. Its finite-word “dimension” is not a critical-exponent upper bound, and the actual two-parameter operator generates a lattice, not the particular thin subgroup used by that diagnostic.

The useful proved outputs are: the distinction between those groups (§1); exact sparse-box counts and finite quotient checks (§2); a precise failure of pointwise fattening (§3); the required centered-trace theorem (§4); and the universal ceiling κ_T ≤ 1/2 on a pure power bound for this operator (§6). Through the specific square-root smoothing interface in Corollary 16 this ceiling becomes κ_C ≤ 1/4. These are ceilings, not attained exponents and not impossibility bounds on every conceivable proof of Corollary 16.

## 1. Which group, which measure, and which exponent?

Write

    n(t) = [[1,t],[0,1]],  w = [[0,1],[1,0]],
    s_{h,k} = n(-k) w n(h) = [[-k,1-kh],[1,h]],
    μ_n = n^{-2} sum_{1≤h,k≤n} δ_{s_{h,k}}.

The determinant of each s_{h,k} is −1. The transformations are x ↦ 1/(x+h)−k. Inversion swaps h,k, so μ_n is symmetric and its permutation average T_{n,p} on X_p=P¹(F_p) is self-adjoint. Constants have eigenvalue 1; write V_0=1^⊥ and λ(n,p)=||T_{n,p}|V_0||. Operator normalization is the average over n² **ordered pairs**, including h=k. This is the two-parameter family in the Corollary-16 proof, whereas the appendix's family g_j=[[-2j,1−4j²],[1,2j]] is a different one-parameter average. Right multiplication of all g_j by w produces x_j=v^j u^{-j}; it does not identify their generated subgroups or their convolution powers.

### 1.1 The actual two-parameter support generates GL₂(Z), with even subgroup SL₂(Z)

For n≥2 and admissible adjacent k,k+1,

    s_{h,k} s_{h,k+1}^{-1} = n(1).

Thus n(1) belongs to the subgroup generated by even-length words. Using its integer powers,

    w = n(k) s_{h,k} n(-h)

belongs to the full generated group. Conjugating n(1) by w gives the lower elementary unipotent [[1,0],[1,1]], also an even word. These two elementary matrices generate SL₂(Z): the Euclidean algorithm reduces an arbitrary determinant-one integer matrix by their powers. Consequently the even-word subgroup is exactly SL₂(Z), and adjoining w gives all determinant ±1 integer matrices. This does not assert that a short random word is remotely uniform on that lattice.

The projective action therefore factors through the usual congruence action. A stabilizer is a conjugate of Γ₀(p), depending on the left/right action convention. Replacing w by [[0,-1],[1,0]] changes the map to −1/x and the determinant convention; no such sign replacement is made in this report.

### 1.2 The x_j subgroup really is infinite index, but its finite-word proxy is misleading

Let u=[[1,2],[0,1]], v=[[1,0],[2,1]], and Λ=〈u,v〉, the free rank-two lattice used in N7. Put

    x_j=v^j u^{-j}=[[1,-2j],[2j,1−4j²]],  H_n=〈x_1,…,x_n〉.

The homomorphism φ:Λ→Z, φ(u)=φ(v)=1, is surjective and kills every x_j. Hence H_n⊂ker φ has infinite index in Λ. The phrase “lies in a free subgroup of finite index” describes the ambient Λ, not H_n.

The elements x_1,…,x_n freely generate H_n. For completeness, set x_0=e and

    y_j=x_j^{-1}x_{j+1}=u^j v u^{-(j+1)}  (0≤j<n).

These are part of the Schreier basis {u^j v u^{-(j+1)}:j∈Z} of ker φ, obtained with coset representatives u^j. Also x_j=y_0…y_{j−1}. This triangular change of free generators proves the assertion. In particular the number of distinct reduced words of length L≥1 over x_j^{±1} is exactly 2n(2n−1)^{L−1}, for every L, including L=50; the cumulative count is 1+2n((2n−1)^L−1)/(2n−2) for n>1.

Nevertheless x_1 has trace −2 and is noncentral parabolic. Indeed −x_1=I+Q with Q≠0 and Q²=0, so ||x_1^m|| grows linearly in |m|. In the normalization of critical exponent in which lattice orbital counts grow as R^{2δ}, the subseries sum_m ||x_1^m||^{-2s} diverges for s≤1/2. Therefore

    δ(H_n) ≥ 1/2  for every n≥1.

Thus a finite ratio log(number of words)/log(6R²) near 0.42, or below, cannot be an upper bound for δ(H_n). It cannot rule out δ>5/6. The same warning applies to the one-parameter involutions: g_j g_{j+1} has trace −2 and is noncentral parabolic. No δ>5/6 claim is proved here either.

## 3. Why sparse-support fattening is not a spectral comparison

Here is a general exact obstruction. Let μ,ν be probability measures on a finite permutation group and suppose μ≤Dν pointwise. For χ₀(g)=#Fix_X(g)−1, we have χ₀≥−1. Since r=Dν−μ is nonnegative with mass D−1,

    sum μ(g)χ₀(g) ≤ D sum ν(g)χ₀(g) + (D−1).          (3.1)

Even a perfectly equidistributed ν leaves the term D−1. Applying an uncentered pointwise majorant and then subtracting the constant eigenvalue therefore does not yield centered decay. The n-sized loss in §2.2 is especially unsuitable for that argument.

Nor does pointwise positivity give positive-semidefinite domination on V₀. For a proper subgroup H<G, take μ uniform on H, ν uniform on G, and D=[G:H]. Then μ≤Dν. On the regular representation, T_ν vanishes on V₀ but T_μ has norm 1 there. Any rule ||T_μ|V₀||≤D||T_ν|V₀|| is false.

These counterexamples invalidate the proposed *inference*. They do not show that the actual μ_n cannot admit a more refined comparison. Such a comparison must control cancellation after subtracting constants, or prove a genuine positive-operator inequality; support cardinalities alone cannot do it.

A fixed-generator expander also does not directly give n-power contraction of a growing alphabet. If an r-element fixed subaverage P with ||P|V₀||≤1−ε occurs with mass r/n in a one-parameter average, the triangle inequality gives only 1−εr/n. This tends to 1. A fixed spectral gap is not a bound λ(n,p)≪n^{-η}.

## 4. An exact missing theorem, with all normalizations

Fix a specified prime range and interval range, for example n≈p^{1/180} arising when the campaign's length L≈p^{1/90} is smoothed at scale √L. These are the phase-0 campaign scales, not hypotheses established by R4. Let W_{n,2k}(γ) count ordered tuples ((h_i,k_i))_{i=1}^{2k}∈([n]²)^{2k} with integer product γ=s_{h_1,k_1}⋯s_{h_{2k},k_{2k}}. Thus γ∈SL₂(Z) and sum_γ W_{n,2k}(γ)=n^{4k}. Repetitions, inverse pairs and identity words are all included.

One sufficient automorphic replacement would be the following uniform **centered weighted word-count theorem**:

> There are explicit constants η>0, A>0, C≥1 and p₀, and an explicitly specified n-range, such that for every prime p≥p₀ and every n in that range one can specify an integer 1≤k≤A log p/log n for which
>
>     sum_γ W_{n,2k}(γ) [#Fix_{P¹(F_p)}(γ mod p)−1]
>          ≤ C^{2k} n^{4k−2kη}.                     (4.1)
>
> The constants and onset are uniform in both n and p.

The exact identity proving sufficiency is

    n^{-4k} sum_γ W_{n,2k}(γ)χ₀(γ mod p)
        = Tr(T_{n,p}^{2k})−1
        = sum_{i=1}^p λ_i^{2k}
        ≥ λ(n,p)^{2k}.                            (4.2)

Consequently (4.1) gives λ(n,p)≤C n^{-η}. To get coefficient 1 at a smaller η'<η, it is enough to require n≥C^{1/(η−η')}; this onset must be propagated, not suppressed.

For odd p, χ₀ is p on projective identity elements, 1 on split elements with two distinct fixed points, 0 on noncentral unipotents with one fixed point, and −1 on nonsplit elements. Thus (4.1) asks for cancellation among weighted split and nonsplit words as well as control of returns. Counting only identity residues is not the same theorem. Nor is counting each distinct word matrix once: W is a multiplicity weight.

The converse direction loses a factor p: λ≤C n^{-η} gives Tr(T^{2k})−1≤p C^{2k}n^{-2kη}. Hence (4.1) is a convenient sufficient trace formulation, not claimed to be necessary with exactly the same constants and k. If k is chosen comparable to log_n p this factor can be budgeted explicitly.

An alternative useful theorem would provide a genuine norm/positive-operator comparison between this word measure and a congruence-uniform smooth lattice average, with all comparison, smoothing and level losses explicit. No such comparison has been proved here. The lattice spectral gap would become relevant only after that missing interface is supplied.

## 5. What the primary sources actually supply

The following is a scope audit of statements read, not a proof of a universal literature negative. Abstract-only access is marked. The original Kim–Sarnak proof and the original Selberg proof were not read; the familiar numerical inputs in §6 are identified as inputs rather than newly verified theorems.

* **Bourgain–Gamburd–Sarnak**, [Generalization of Selberg's 3/16 theorem and affine sieve, arXiv:0912.5021](https://arxiv.org/html/0912.5021), Theorems 1.1–1.3. The gap is for a fixed finitely generated Λ with δ>1/2, with ε depending on Λ. The orbital congruence count has main term c_Λ T^{2δ}/|SL₂(q)| and error O(q³T^{2δ−ε₁}), with group-dependent constants and permitted moduli. Its expansion argument uses Bourgain–Gamburd input. It is not a BG-free derivation of (4.1) for the moving H_n, and its lattice point weight is not W_{n,2k}.

* **Bourgain–Kontorovich–Sarnak**, [Sector Estimates for Hyperbolic Isometries, arXiv:1001.4541](https://arxiv.org/html/1001.4541), Theorems 1.12 and 1.13. For fixed Γ with δ>1/2 and a spectral-gap parameter Θ, the congruence-sector theorem counts a smooth weight f, with an error involving (1+S_{∞,T}f)^{6/7}T^{(12δ+2Θ)/7}, together with the stated bad-modulus correction. It is uniform in appropriate levels and cosets, not automatically in changing Γ or in arbitrary word-multiplicity weights. Encoding W in f with acceptable support and Sobolev losses is precisely an unproved step. Theorem 1.12 records the Θ=5/6 input under δ>5/6; our finite proxy cannot test that hypothesis.

* **Bourgain–Kontorovich**, [On representations of integers in thin subgroups of SL₂(Z), arXiv:1001.4534](https://arxiv.org/html/1001.4534), Theorem 2.1. The orbital-counting input has the same smooth-weight/Sobolev issue. Its fixed thin-group representation problem does not provide the moving two-parameter estimate (4.1).

* **Calderón–Magee**, [Explicit spectral gap for Schottky subgroups of SL₂(Z), arXiv:2303.17950v2](https://arxiv.org/html/2303.17950v2), Theorem 2 and §2.2. For Schottky Γ with δ>4/5, put t_Γ=δ/6+2/3. For β∈(t_Γ,δ), sufficiently large prime factors (threshold depending on Γ,β) exclude new eigenvalues below β(1−β). Here Schottky means convex cocompact; the definition uses disks with pairwise disjoint closures. H_n contains parabolics and does not meet that hypothesis. Even an applicable fixed-group statement would leave the moving onset and the measure comparison open. The paper's Theorem 1 restates the fixed-group Gamburd 5/6 threshold; it is not a proof of (4.1).

* **Salehi Golsefidy–Varjú**, [Expansion in perfect groups, arXiv:1108.4900](https://arxiv.org/html/1108.4900), abstract and Theorem 1. A fixed finite symmetric generating set gives expansion over the specified squarefree congruence quotients when the connected Zariski closure is perfect. This provides a qualitative fixed-set gap, not a uniform n-power bound for growing S_n, and does not identify the exponent or onset required by (4.1). The theorem's exact bad-prime/modulus conventions must be retained in any application.

* **Bourgain–Kontorovich**, [On Zaremba's Conjecture, arXiv:1107.3776](https://arxiv.org/abs/1107.3776), abstract inspected. The stated result concerns a density-one set of denominators. It does not assert that every prime has the campaign's property, nor does its abstract supply the required quantitative operator theorem. Its full proof was not audited in this task.

* **Shkredov**, [arXiv:2603.14116v2](https://arxiv.org/html/2603.14116v2), Lemmas 14–15 and Corollary 16. The text explicitly obtains the two-dimensional family by taking S=[n]² and inversion, and distinguishes it from the one-dimensional Kesten/free-group first stage. The proof smooths at h≈√L. This is why the operator and Corollary exponents are separated here. The displayed SL₂ formulation and 1/x example have a determinant-sign mismatch if read literally; §1 gives the precise GL₂/PGL₂ realization.

The general Helfgott, Murphy BSG and survey references in the task are background to other routes. Their full proofs were not newly read for R4, and no new R4 constant is attributed to them. The task-specified MMS one-parameter family and Zhang's discussion of fixed-generating-set dependence were used as context, not as a missing weighted theorem.

## 6. What can be said rigorously about the best exponent?

### 6.1 A universal ceiling for the actual operator

For 1≤n<p, T_{n,p} sends the point mass at ∞ to the uniform measure on {−1,…,−n}: s_{h,k}∞=−k, with h providing exactly n repetitions. Use the counting inner product on X_p, and let e=δ_∞−(p+1)^{-1}1. Then

    ||e||²=1−1/(p+1),
    ||T e||²=1/n−1/(p+1).

Therefore

    λ(n,p)² ≥ (p+1−n)/(np).                        (6.1)

If n→∞ and n=o(p), any uniform inequality λ(n,p)≤C n^{-κ_T} with fixed C forces κ_T≤1/2. This is proved independently of every automorphic input. No estimate attaining 1/2 has been proved in this report.

### 6.2 Transfer through the existing square-root smoothing proof

Assume, conditionally, λ(h,p)≤C h^{-η} for every scale h needed by the proof, with 0<η≤1 and explicit uniform C/onset. Let L be the block length in Corollary 16. Its main smoothed error is O(C h^{-η}√(|A||B|)). The boundary estimate has terms

    |A||B|/p · (h/L+h²/L²)
      + O(C√(|A||B|)[h^{1−η}/√L+h^{2−η}/L]).

Taking an integer h≈√L gives O((1+C)√(|A||B|)L^{-η/2}), using √(|A||B|)≤p. Thus this specified interface delivers

    κ_C = η/2,  with explicit coefficient/onset still to be propagated. (6.2)

Combining (6.1) and (6.2), the largest possible pure-power exponent obtainable by first proving this operator bound and then applying this square-root smoothing calculation is κ_C≤1/4. This is a ceiling on that interface; a direct proof using additional interval invariance could behave differently. The phase-0 scales L≈p^{1/90}, h≈p^{1/180} also show why replacing log_h p by log_L p silently loses a factor of two.

### 6.3 Why 3/16 or 975/4096 does not determine κ_C

For a complementary parameter s with Laplace eigenvalue s(1−s), Selberg's stated input 3/16 corresponds to s≤3/4. The stated Kim–Sarnak input 975/4096 corresponds to s≤39/64, since 39·25=975 and 64²=4096. These are bounds for automorphic spectral parameters. They are not bounds on λ(n,p) without a comparison from the particular discrete probability measure μ_n to the automorphic action. Reporting 1−s, 2(1−s), or a quotient of these as κ_C would omit that comparison and its losses.

**Certified positive κ from this R4 replacement: none.** The exact positive exponent, coefficient, and onset remain open. The numbers 1/2 and 1/4 above are proved upper ceilings for specified formulations, not supplied lower guarantees. This answers the “best κ” request to the extent presently justified; the optimal achievable exponent is not known from this audit.

## 7. Negative list and recommended next gate

1. The integer subgroup H_n is infinite index; this does not make the actual T₂ generating group thin.
2. A small finite-word logarithmic proxy is not a critical-exponent upper bound; parabolics already force δ(H_n)≥1/2.
3. Full generation of SL₂(Z) does not make μ_n a uniform lattice-ball measure.
4. Pointwise fattening cannot be centered after the fact without the additive D−1 loss in (3.1); it is not positive-operator domination.
5. Word support counts cannot replace multiplicity weights, and return probabilities cannot replace the full centered projective trace.
6. Fixed-set expansion and fixed-group orbital counts leave moving alphabet, word length, level, Sobolev loss, coefficients and onsets unresolved.
7. Calderón–Magee's convex-cocompact hypothesis fails for H_n as defined; its numerical threshold cannot simply be applied.
8. The finite experiments are outside the campaign's extreme tiny-power regime and certify no uniform exponent.
9. The original one-parameter appendix estimate does not automatically settle the actual two-parameter Lemma-15 input.
10. No assertion that every conceivable automorphic route is dead, and no claim that the original conjecture is solved, follows from this report.

The next valuable R4 gate is a proof or a sharply quantified obstruction for (4.1), or for an explicit positive-operator comparison that implies it. Do not spend a new campaign merely improving lattice-point constants before specifying how the discrete word weights are transferred. The finite-dimensional algebra in §1 suggests formulating that gate directly for the actual T₂ family on the full lattice, rather than trying to kill it using δ(H_n).

## Appendix: reproducible exact counting kernels

No separate script file was written because the inbox protocol permits only report-path edits. These self-contained Node kernels reproduce the exact counting definitions; large parameter grids should be run one at a time under the stated memory cap.

The following reproduces the complete length-50 quotient balls in §2.3:

```javascript
// node --max-old-space-size=384
const p=31, order=p*(p*p-1)/2;
function mul(a,b) {
  return [(a[0]*b[0]+a[1]*b[2])%p,(a[0]*b[1]+a[1]*b[3])%p,
          (a[2]*b[0]+a[3]*b[2])%p,(a[2]*b[1]+a[3]*b[3])%p];
}
function canon(a) {
  a=a.map(x=>(x%p+p)%p);
  const t=a.find(x=>x!==0);
  return t>p-t ? a.map(x=>(p-x)%p) : a;
}
for (const n of [2,3,5,10,15,50]) {
  const S=[];
  for (let j=1;j<=n;j++) {
    const a=canon([1,-2*j,2*j,1-4*j*j]);
    S.push(a,canon([a[3],-a[1],-a[2],a[0]]));
  }
  let front=[[1,0,0,1]], seen=new Set(['1,0,0,1']), counts=[1], L=0;
  while (L<50 && front.length) {
    const next=[];
    for (const a of front) for (const b of S) {
      const c=canon(mul(a,b)), key=c.join(',');
      if (!seen.has(key)) { seen.add(key); next.push(c); }
    }
    L++; front=next; counts.push(seen.size);
    if (seen.size===order) break;
  }
  console.log({p,n,counts,saturated_at:seen.size===order?L:null,
               ball50:seen.size,order});
}
```

    for (let k=d;k<=n;k+=d) phi[k]-=phi[k]/d;
