# A108211: floor formula — proof draft v1 (2026-08-16, Claude Fable 5)

**Theorem.** For every integer n >= 1,
  16n^2 + 1 = floor( 1 / D(n) ),  where
  D(n) = 1/(4n) - log 2 + Sum_{k=n+1}^{2n} 1/k.

**Status: DRAFT — pending adversarial review + small-n numeric check + Lean.**

## Step 1: exact series for D(n)

Catalan's identity: Sum_{k=n+1}^{2n} 1/k = Sum_{j=1}^{2n} (-1)^{j+1}/j.
(Proof: induction or H_{2n} - H_n = H_{2n} - 2*(1/2)H_n.)

Since log 2 = Sum_{j=1}^inf (-1)^{j+1}/j (alternating harmonic series),
  log 2 - Sum_{k=n+1}^{2n} 1/k = Sum_{j=2n+1}^inf (-1)^{j+1}/j
    = Sum_{m>=n} [ 1/(2m+1) - 1/(2m+2) ]      (pair consecutive terms)
    = Sum_{m>=n} 1/((2m+1)(2m+2)) =: T(n).
All terms positive; absolutely convergent. Hence

  D(n) = 1/(4n) - T(n).                                            (*)

## Step 2: goal as two inequalities

floor(1/D(n)) = 16n^2+1  <=>  16n^2+1 <= 1/D(n) < 16n^2+2
              <=>  1/(16n^2+2) < D(n) <= 1/(16n^2+1)
              <=>  f1(n) <= T(n) < f2(n), where
  f1(n) := 1/(4n) - 1/(16n^2+1),   f2(n) := 1/(4n) - 1/(16n^2+2).

(Strictness: D(n) = 1/(16n^2+1) would need T rational-with-log2... in fact
T(n) is irrational-free? No: T(n) = log 2 - rational, and log 2 irrational,
so T(n) is irrational, while f1(n) is rational; hence T(n) = f1(n) is
impossible and both inequalities are automatically strict. This also
upgrades <= to <; floor condition needs only the non-strict form.)

## Step 3: first-order telescoping

Claim A: T(n) < 1/(4n+1).
Proof: 4/((4m+1)(4m+5)) - 1/((2m+1)(2m+2))
     = [4(2m+1)(2m+2) - (4m+1)(4m+5)] / ((4m+1)(4m+5)(2m+1)(2m+2))
     = [16m^2+24m+8 - (16m^2+24m+5)] / (...)
     = 3 / ((4m+1)(4m+5)(2m+1)(2m+2)) > 0.
Since Sum_{m>=n} 4/((4m+1)(4m+5)) = Sum_{m>=n} [1/(4m+1) - 1/(4m+5)]
telescopes to 1/(4n+1), we get the EXACT identity

  T(n) = 1/(4n+1) - 3*U(n),  U(n) := Sum_{m>=n} 1/((4m+1)(4m+5)(2m+1)(2m+2)).  (**)

## Step 4: bounds on the quartic tail U(n)

Denominator: (4m+1)(4m+5)(2m+1)(2m+2) = q(m). Note
q(m) = (16m^2+24m+5)(4m^2+6m+2) — a quartic ~ 64 m^4.

Upper bound: q(m) > 64 m^3 (m+1) ... choose clean telescopes:
Claim B (upper): 1/q(m) < (1/3)*[ h(m) - h(m+1) ] with h(m) = 1/( (4m+1)(4m+2)(4m+3) )*c ...

To keep verification simple we instead bound U(n) between two explicit
telescoping cubics. Let  P(m) = (4m+1)(2m+1)(4m+3).  Then define
  Delta(m) := 1/P(m) - 1/P(m+1).
Compute: P(m) = 32m^3 + 48m^2 + 22m + 3.
  P(m+1) = 32m^3 + 144m^2 + 214m + 105.
  Delta(m) = (P(m+1)-P(m)) / (P(m)P(m+1)) = (96m^2 + 192m + 102)/(P(m)P(m+1)).

We need constants c1 < c2 with
  c1 * Delta(m) < 1/q(m) < c2 * Delta(m)   for all m >= 1,
i.e.  c1 * (96m^2+192m+102) * q(m) < P(m)P(m+1) < c2 * (96m^2+192m+102) * q(m).
Leading order: P*P' ~ 1024 m^6, (96m^2)*q ~ 96*64 m^6 = 6144 m^6, ratio -> 1/6.
So take c1, c2 near 1/6 with explicit polynomial verification:
  Claim C: for all m >= 1,
    (1/6)*Delta(m)*(1 - 1/(2m)) < 1/q(m) < (1/6)*Delta(m)*(1 + 1/(2m)) ...

## Step 5: small n

Verify n = 1..n0 numerically with interval arithmetic (log 2 to 30 digits).
n=1: D = 1/4 - log2 + 1/2 = 0.75 - 0.693147... = 0.056852...;
1/D = 17.5894...; floor = 17 = 16+1 ✓.
