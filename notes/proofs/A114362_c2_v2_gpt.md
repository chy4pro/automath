quirk in this capture:
1. It strips the leading backslash from LaTeX delimiters `\(`, `\)`, `\[`,

   those delimiters (the actual LaTeX: `\frac{...}`, `\sum`, `\zeta`, `^{...}`,

# A114362 Conjecture 2 (Ordowski): Corrected Proof v2

## Theorem

For every integer (n\ge 2), define
[
t_n:=\frac{\zeta(2n)}{\zeta(n)^2},
\qquad
y_n:=\frac{1-t_n}{1+t_n},
]
and
[
S_n:=2^{-n}+3^{-n}+5^{-n}+7^{-n}.
]
Then the explicit bound
[
\boxed{\left|y_n-S_n\right|\le 24\cdot 11^{-n}}
]
holds for every (n\ge2). Consequently,
[
\frac{1-t_n}{1+t_n}
===================

2^{-n}+3^{-n}+5^{-n}+7^{-n}+O(11^{-n}).
]

Moreover,
[
\boxed{y_n-S_n\sim 11^{-n}}
\qquad(n\to\infty),
]
that is,
[
\lim_{n\to\infty}\frac{y_n-S_n}{11^{-n}}=1.
]

## Proof

Fix an integer (n\ge2). Throughout the proof, products indexed by (p) are products over primes.

### 1. Euler-product representation

For every prime (p), set
[
x_p:=p^{-n},
\qquad
q_p:=\frac{1-x_p}{1+x_p}.
]
Then (0<x_p\le 2^{-n}\le \frac14), and
[
\sum_p x_p
\le
\sum_{m=2}^{\infty}m^{-n}
<\infty.
]

For completeness, the convergence of the Euler product may be justified directly. For (0\le u\le\frac14),
[
-\log(1-u)
==========

\int_0^u\frac{dv}{1-v}
\le
\frac{u}{1-u}
\le
\frac43u.
]
Hence
[
\sum_p\left|-\log(1-p^{-n})\right|
\le
\frac43\sum_p p^{-n}
<\infty.
]
Thus the Euler product for (\zeta(n)) converges absolutely.

More explicitly, for a finite prime cutoff (P),
[
\prod_{p\le P}(1-p^{-n})^{-1}
=============================

\sum_{\substack{m\ge1\\text{every prime divisor of }m\text{ is }\le P}}
m^{-n},
]
by expanding the finite product of geometric series and using unique factorization. As (P\to\infty), the right-hand side increases to
[
\sum_{m=1}^{\infty}m^{-n}=\zeta(n).
]
Therefore
[
\zeta(n)=\prod_p(1-p^{-n})^{-1}.
]
The same argument applies to (\zeta(2n)).

For each finite cutoff (P),
[
\frac{\displaystyle\prod_{p\le P}(1-p^{-2n})^{-1}}
{\displaystyle\left(\prod_{p\le P}(1-p^{-n})^{-1}\right)^2}
===========================================================

# \prod_{p\le P}\frac{(1-p^{-n})^2}{1-p^{-2n}}

\prod_{p\le P}\frac{1-p^{-n}}{1+p^{-n}}.
]
Passing to the limit gives
[
t_n
===

\prod_p q_p.
]

This product is also absolutely convergent in the infinite-product sense. Indeed,
[
|\log q_p|
==========

# \log\frac{1+x_p}{1-x_p}

\log(1+x_p)-\log(1-x_p),
]
and, since (\log(1+u)\le u),
[
|\log q_p|
\le
x_p+\frac43x_p
==============

\frac73x_p.
]
Thus
[
\sum_p|\log q_p|<\infty,
]
so the product converges to a strictly positive number.

Define the tail product
[
R_{11}:=\prod_{p\ge11}q_p.
]
Then
[
t_n=q_2q_3q_5q_7R_{11},
]
and
[
0<R_{11}<1.
]

### 2. Exact Möbius composition

For (a,b\in[0,1)), define
[
a\oplus b:=\frac{a+b}{1+ab}.
]
This operation maps ([0,1)^2) into ([0,1)), because
[
1-(a\oplus b)
=============

\frac{(1-a)(1-b)}{1+ab}>0.
]

It is associative. Direct calculation gives
[
(a\oplus b)\oplus c
===================

# \frac{a+b+c+abc}{1+ab+ac+bc}

a\oplus(b\oplus c).
]

Also define
[
\Phi(u):=\frac{1-u}{1+u}
\qquad(0<u\le1).
]
If
[
q(a):=\frac{1-a}{1+a},
]
then for (a\in[0,1)) and (R\in(0,1]),
[
\Phi(q(a)R)
===========

a\oplus\Phi(R).
]
Indeed,
[
\Phi(q(a)R)
===========

\frac{(1+a)-(1-a)R}{(1+a)+(1-a)R}.
]
On the other hand, writing
[
b=\Phi(R)=\frac{1-R}{1+R},
]
we have
[
a\oplus b
=========

\frac{a(1+R)+(1-R)}
{(1+R)+a(1-R)}
==============

\frac{(1+a)-(1-a)R}
{(1+a)+(1-a)R}.
]

Define
[
r:=\Phi(R_{11})=\frac{1-R_{11}}{1+R_{11}}.
]
Then (0<r<1). Iterating the preceding identity over (p=2,3,5,7) gives
[
y_n
===

x_2\oplus
\left(
x_3\oplus
\left(
x_5\oplus
\left(
x_7\oplus r
\right)
\right)
\right).
]
By associativity, if
[
A:=x_2\oplus x_3\oplus x_5\oplus x_7,
]
then
[
\boxed{y_n=A\oplus r}.
]

### 3. Uniform bound for the tail (r)

We first use the elementary finite-product inequality
[
1-\prod_{j=1}^m u_j
\le
\sum_{j=1}^m(1-u_j),
\qquad 0\le u_j\le1.
]
It follows by induction from
[
1-uv=(1-u)+u(1-v)\le(1-u)+(1-v).
]

Applying this to finite partial products of (R_{11}), and then passing to the limit, yields
[
1-R_{11}
\le
\sum_{p\ge11}(1-q_p).
]
Since
[
1-q_p
=====

# 1-\frac{1-x_p}{1+x_p}

\frac{2x_p}{1+x_p}
\le
2x_p,
]
we obtain
[
1-R_{11}
\le
2\sum_{p\ge11}p^{-n}
\le
2\sum_{k=11}^{\infty}k^{-n}.
]

Because (u\mapsto u^{-n}) is decreasing,
[
\begin{aligned}
\sum_{k=11}^{\infty}k^{-n}
&=
11^{-n}+\sum_{k=12}^{\infty}k^{-n}\
&\le
11^{-n}+\int_{11}^{\infty}u^{-n},du\
&=
11^{-n}+\frac{11^{1-n}}{n-1}\
&=
11^{-n}\left(1+\frac{11}{n-1}\right).
\end{aligned}
]
Since (n\ge2),
[
1+\frac{11}{n-1}\le12.
]
Therefore
[
1-R_{11}\le24\cdot11^{-n}.
]

Finally,
[
0\le r
======

\frac{1-R_{11}}{1+R_{11}}
\le
1-R_{11},
]
so
[
\boxed{0\le r\le24\cdot11^{-n}}.
]

### 4. Uniform bound for the four-prime composition defect

For (a,b\in[0,1)), define
[
\delta(a,b):=a+b-(a\oplus b).
]
Direct algebra gives the exact identity
[
\delta(a,b)
===========

# a+b-\frac{a+b}{1+ab}

\frac{ab(a+b)}{1+ab}.
]
Hence
[
0\le\delta(a,b)\le ab(a+b).
]

Define
[
b_5:=x_5\oplus x_7,
\qquad
b_3:=x_3\oplus b_5,
\qquad
A:=x_2\oplus b_3.
]
Also let
[
F:=S_n-A.
]
By telescoping,
[
\begin{aligned}
F
&=
(x_5+x_7-b_5)
+(x_3+b_5-b_3)
+(x_2+b_3-A)\
&=
\delta(x_5,x_7)
+\delta(x_3,b_5)
+\delta(x_2,b_3).
\end{aligned}
]

Because
[
0<x_7\le x_5\le x_3\le x_2,
]
we have
[
b_5\le x_5+x_7\le2x_5
]
and
[
b_3\le x_3+b_5
\le x_3+x_5+x_7
\le3x_3.
]

For the innermost defect,
[
\begin{aligned}
\delta(x_5,x_7)
&\le
x_5x_7(x_5+x_7)\
&\le
2x_5^2x_7\
&=
2\cdot175^{-n}.
\end{aligned}
]

For the middle defect,
[
\begin{aligned}
\delta(x_3,b_5)
&\le
x_3b_5(x_3+b_5)\
&\le
x_3(2x_5)(3x_3)\
&=
6x_3^2x_5\
&=
6\cdot45^{-n}.
\end{aligned}
]

For the outer defect, since (b_3\le3x_3) and (x_3\le x_2),
[
x_2+b_3\le x_2+3x_3\le4x_2.
]
Therefore
[
\begin{aligned}
\delta(x_2,b_3)
&\le
x_2b_3(x_2+b_3)\
&\le
x_2(3x_3)(4x_2)\
&=
12x_2^2x_3\
&=
12\cdot12^{-n}.
\end{aligned}
]

Combining these three estimates,
[
F
\le
12\cdot12^{-n}
+
6\cdot45^{-n}
+
2\cdot175^{-n}.
]
Since (45>12) and (175>12),
[
45^{-n}\le12^{-n},
\qquad
175^{-n}\le12^{-n},
]
and hence
[
\boxed{0\le F=S_n-A\le20\cdot12^{-n}}.
]

### 5. Completion of the (O(11^{-n})) estimate

For (a,b\in[0,1)),
[
a\oplus b-a
===========

\frac{b(1-a^2)}{1+ab}
\ge0,
]
so
[
a\oplus b\ge a.
]
Also,
[
a\oplus b=\frac{a+b}{1+ab}\le a+b.
]

Applying these inequalities to (y_n=A\oplus r) gives
[
A\le y_n\le A+r.
]
Since (S_n=A+F),
[
-F\le y_n-S_n\le r.
]

The preceding sections give
[
F\le20\cdot12^{-n}
\le20\cdot11^{-n}
\le24\cdot11^{-n}
]
and
[
r\le24\cdot11^{-n}.
]
Therefore
[
\boxed{\left|y_n-S_n\right|\le24\cdot11^{-n}}
]
for every integer (n\ge2).

This proves
[
y_n
===

2^{-n}+3^{-n}+5^{-n}+7^{-n}+O(11^{-n}).
]

### 6. Sharper asymptotic

We now prove
[
y_n-S_n\sim11^{-n}.
]

Set
[
u_n:=11^{-n}
]
and define
[
R_{13}:=\prod_{p\ge13}q_p.
]
Then
[
R_{11}=q_{11}R_{13},
\qquad
q_{11}=\frac{1-u_n}{1+u_n}.
]

As in Section 3,
[
0\le1-R_{13}
\le
2\sum_{p\ge13}p^{-n}
\le
2\sum_{k=13}^{\infty}k^{-n}.
]
The integral estimate gives
[
\sum_{k=13}^{\infty}k^{-n}
\le
13^{-n}\left(1+\frac{13}{n-1}\right).
]
Therefore
[
0\le
\frac{1-R_{13}}{u_n}
\le
2\left(\frac{11}{13}\right)^n
\left(1+\frac{13}{n-1}\right).
]
For (n\ge2),
[
1+\frac{13}{n-1}\le14,
]
and hence
[
0\le
\frac{1-R_{13}}{u_n}
\le
28\left(\frac{11}{13}\right)^n
\longrightarrow0.
]
Thus
[
1-R_{13}=o(u_n).
]

Now
[
\begin{aligned}
1-R_{11}
&=
1-q_{11}R_{13}\
&=
(1-q_{11})+q_{11}(1-R_{13}).
\end{aligned}
]
Since
[
1-q_{11}
========

# 1-\frac{1-u_n}{1+u_n}

\frac{2u_n}{1+u_n},
]
we have
[
\frac{1-R_{11}}{u_n}
====================

\frac{2}{1+u_n}
+
q_{11}\frac{1-R_{13}}{u_n}.
]
The first term tends to (2), while the second tends to (0). Hence
[
\frac{1-R_{11}}{u_n}\longrightarrow2.
]
In particular, (R_{11}\to1). Therefore
[
\frac{r}{u_n}
=============

\frac{(1-R_{11})/u_n}{1+R_{11}}
\longrightarrow
\frac22
=======

1.

]

Next,
[
0\le A\le S_n\le4\cdot2^{-n},
]
so (A\to0). Also (r\to0). From (y_n=A\oplus r),
[
\begin{aligned}
y_n-A
&=
\frac{A+r}{1+Ar}-A\
&=
\frac{r(1-A^2)}{1+Ar}.
\end{aligned}
]
Since (S_n=A+F),
[
y_n-S_n
=======

\frac{r(1-A^2)}{1+Ar}-F.
]
Dividing by (u_n=11^{-n}),
[
\frac{y_n-S_n}{u_n}
===================

\frac{r}{u_n}
\frac{1-A^2}{1+Ar}
------------------

\frac{F}{u_n}.
]

We have already proved
[
\frac{r}{u_n}\longrightarrow1
]
and
[
\frac{1-A^2}{1+Ar}\longrightarrow1.
]
Furthermore,
[
0\le
\frac{F}{u_n}
\le
20\frac{12^{-n}}{11^{-n}}
=========================

20\left(\frac{11}{12}\right)^n
\longrightarrow0.
]
Consequently,
[
\boxed{
\lim_{n\to\infty}
\frac{y_n-S_n}{11^{-n}}
=1
}.
]

Thus
[
\boxed{
\frac{1-t_n}{1+t_n}
-------------------

\left(2^{-n}+3^{-n}+5^{-n}+7^{-n}\right)
\sim11^{-n}
}.
]

(\square)
