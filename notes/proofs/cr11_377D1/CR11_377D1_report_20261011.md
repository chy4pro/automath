## 2. Exact Fourier minorant

Define the periodic indicator

I(t) = 1 if {t} > 1/2, and I(t) = 0 otherwise.

### Theorem 1

For every real t,

q(t) := 1/4 - (1/2) sin(2πt) - (1/4) cos(4πt) <= I(t).

Moreover, the integral of q over [0,1] is 1/4, and no real trigonometric polynomial of degree at most two lying everywhere below I has a larger integral.

### Proof

Put s=sin(2πt). The identity cos(4πt)=1-2s² gives

q(t)=(s²-s)/2.

If 0 <= {t} <= 1/2, then 0 <= s <= 1, so s²-s=s(s-1)<=0. Thus q(t)<=0=I(t), including the two boundary points.

If 1/2 < {t} < 1, put r=-s, so 0<r<=1. Then

q(t)=(r²+r)/2 <= (1+1)/2=1=I(t).

The two nonconstant Fourier terms have integral zero, proving that the mean is 1/4.

For optimality, let T be any real trigonometric polynomial of degree at most two. Averaging each exponential frequency over the four points 0,1/4,1/2,3/4 shows exactly that

integral_0^1 T(t) dt = [T(0)+T(1/4)+T(1/2)+T(3/4)]/4.

Indeed, for each integer k with 0<|k|<=2, the sum of e(kj/4) over j=0,1,2,3 is zero, by the finite geometric-sum identity. If T<=I, its values at the first three displayed points are at most zero, and its value at 3/4 is at most one. Its integral is therefore at most 1/4. This bound is attained by q, whose four values are 0,0,0,1. This proves all assertions.

### Exact weighted consequence

For 1<y<z, define

W(n;y,z) = sum_{y<p<=z, {n/p}>1/2} 1/p,

E_h(n;y,z) = sum_{y<p<=z} e(hn/p)/p, for h=1,2.

Multiplying Theorem 1 by each positive weight 1/p and summing gives

W(n;y,z)
>= (1/4)[M(z)-M(y)] - (1/2) Im E_1(n;y,z) - (1/4) Re E_2(n;y,z)
>= (1/4)[M(z)-M(y)] - (1/2)|E_1(n;y,z)| - (1/4)|E_2(n;y,z)|.       (2.1)

The second inequality uses Im w<=|w| and Re w<=|w|. It does not assume a sign for either Fourier sum. There is no approximation, smoothing, or endpoint error in (2.1).

## 3. Fully numerical conditional intermediate theorem

The next hypothesis is the exact estimate that this attempt failed to prove. Restricting its upper endpoint to sqrt(n) is intentional; extending it to ranges near n makes it false, as shown in Section 6.

For a fixed integer n, set

t=log n, s=t^(3/4), y=exp(s), z=sqrt(n).

**Hypothesis (H) at n.** For h=1 and h=2, every real P with y<=P<z, and every real Q with P<=Q<=min(2P,z),

|sum_{P<p<=Q} e(hn/p)| <= P/(log P)².                             (H)

### Theorem 2 — conditional

For every integer n >= ceil(exp(256)) satisfying (H),

sum_{exp((log n)^(3/4))<p<=n, {n/p}>1/2} 1/p
>= (1/4)[M(n)-M(exp((log n)^(3/4)))] - 1/3.                       (3.1)

In particular, the same n satisfies the brief's inequality (C), with its original error constant 1.

### Proof

Since t>=256 and t^(1/4)>=4, s<=t/4<t/2. Thus y<z. Also s>=64, so every Mertens estimate used below has argument exceeding 286.

Partition (y,z] into consecutive intervals (P_j,Q_j], where P_j=2^j y and Q_j=min(2P_j,z), for those integers j>=0 with P_j<z. For a fixed interval define

A_j(v)=sum_{P_j<p<=v} e(hn/p), for P_j<=v<=Q_j.

Finite-sum partial summation gives exactly

sum_{P_j<p<=Q_j} e(hn/p)/p
= A_j(Q_j)/Q_j + integral_{P_j}^{Q_j} A_j(v)/v² dv.

By (H), the absolute value of this expression is at most

[P_j/(log P_j)²] [1/Q_j + integral_{P_j}^{Q_j} dv/v²]
= [P_j/(log P_j)²] [1/Q_j + 1/P_j - 1/Q_j]
= 1/(log P_j)².

For a decreasing positive function g, g(j)<=integral_{j-1}^j g(v)dv for every integer j>=1. Applying this to g(v)=(s+v log 2)^(-2) and enlarging the finite sum gives, for each h=1,2,

|E_h(n;y,z)|
<= sum_{j>=0} 1/(s+j log 2)²
<= 1/s² + integral_0^infinity dv/(s+v log 2)²
= 1/s² + 1/(s log 2).                                           (3.2)

The elementary identity log 2=integral_1^2 dx/x shows 1/2<log 2<1. Since s>=64, (3.2) yields

|E_h(n;y,z)| < 1/4096 + 1/32 = 129/4096.                         (3.3)

By (2.1), and because all primes counted in W(n;y,z) are also counted in W(n;y,n),

W(n;y,n)
>= (1/4)[M(z)-M(y)] - (3/4)[1/s²+1/(s log 2)].                  (3.4)

The two supplied Mertens estimates give

M(n)-M(z)
< log log n - log log z + 1/(2t²) + 1/[2(t/2)²]
= log 2 + 5/(2t²).                                             (3.5)

Combining (3.4) and (3.5), the total amount to subtract from (1/4)[M(n)-M(y)] is strictly less than

R(t) = (log 2)/4 + 5/(8t²) + (3/4)[1/s²+1/(s log 2)].

Every term has an explicit bound. Namely,

(log 2)/4 < 1/4,

5/(8t²) <= 5/524288 < 1/4096,

(3/4)[1/s²+1/(s log 2)] < 387/16384.

Consequently,

R(t) < 1/4 + 1/4096 + 387/16384 = 4487/16384 < 1/3,

where the last inequality is the integer comparison 13461<16384. This proves even a strict version of (3.1), and hence proves the stated non-strict version.

### 6.2 Requiring cancellation all the way to n: a false auxiliary claim

A version of (H) for every P up to n is false, not merely unproved. Here is an explicit obstruction, using only the supplied θ bound.

For every integer n>=ceil(exp(100)), put t=log n, P=5n/6, and Q=n. For P<p<=n,

1<=n/p<6/5,

so

Re e(n/p) >= cos(2π/5) = (sqrt(5)-1)/4 > 1/4.

Both P and n exceed 678407: e>2, so n>=e^100>2^100, which is already more than sufficient for this assertion. Also log P>t-1>=99, since 5/6>e^(-1). The supplied θ bounds therefore give

θ(n)-θ(P) > n/6 - n/(40t) - P/(40 log P)
> n/6 - n/20
= 7n/60 > n/12.

The middle inequality uses t>1, log P>1, and P<n to bound the two subtracted terms in total by n/20. Since each log p<=t,

π(n)-π(P) > n/(12t),

and hence

|sum_{P<p<=n} e(n/p)| >= Re sum_{P<p<=n} e(n/p) > n/(48t).

For t>=100, (t-1)²>40t, since t²-42t+1>0. It follows that

n/(48t) > (5n/6)/(t-1)² > P/(log P)².

Thus this interval contradicts the proposed all-the-way-to-n version of (H). Discarding primes above sqrt(n) in Theorem 2 fixes this issue at a bounded, explicitly charged harmonic cost. This single-interval counterexample is not an attempt to obtain growth by summing prime-counting endpoint errors.

### 6.3 Low-order and repeated elementary differencing: insufficient scale

I did not prove an exponential-sum theorem for the subexponential lower cutoff. The following are exact scale calculations documenting the obstruction in the elementary route considered; they are not being presented as a substitute exponential-sum estimate.

Write L=log n and take P=exp(L^(3/4)). For g(x)=hn/x,

g''(x)=2hn/x³,

and for x in [P,2P],

hn/(4P³) <= g''(x) <= 2hn/P³.

Already at L>=256, n/P³=exp(L-3L^(3/4))>=exp(L/4). The phase is far beyond the useful small-second-derivative scale. In particular, the square-root expression arising in the elementary second-derivative route obeys the exact comparison

sqrt(hn/P)/P = sqrt(h) exp((L-3L^(3/4))/2) >= exp(L/8)>1.

Thus that contribution exceeds the trivial length scale, even before any constants or prime weights are paid for.

Repeated differentiation/differencing was also considered. Its high-order derivative is exactly

|g^(k)(x)|=k! hn/x^(k+1).

To make this derivative at most one even at x=2P, one necessarily needs

(k+1)(log P+log 2) >= L+log h+log(k!) >= L.

Put u=L^(1/4), so log P=u³. Since log 2<1 and u/(1+1/u³)>u-1 for u>=1, this necessary condition gives k+1>u-1, hence k>u-2. Thus the order cannot remain fixed.

The elementary repeated-differencing scheme considered has a loss exponential in that order. To expose the scale issue, even the optimistic model with exponent denominator 2^(k-2) would supply an exponent no larger than

(log P)/2^(k-2) < 16u³/2^u <= 16/u, for u>=16.

The last inequality follows from u^4<=2^u for u>=16. Equality holds at u=16, and the logarithmic derivative of 2^u/u^4 is log 2-4/u>1/2-1/4>0 thereafter. For u>=32, 16/u<=1/2. In contrast, the factor 1/(log P)² in (H) requires an exponent 2 log log P=6 log u>6. Thus this optimistic model cannot supply (H). The model is a diagnosis of the specific approach, not a claimed bound on the true sum and not an impossibility theorem for other exponential-sum methods.

Introducing a prime decomposition of Vaughan type does not by itself fill this gap. I did not derive explicit type I and type II estimates with a sufficiently mild dependence on the growing differentiation order. No Vaughan identity or type I/II estimate is silently invoked anywhere in the proved results.

### 6.4 A reciprocal-frequency moment idea: no uniform local control obtained

I also considered high moments in the parameter n. A sum of k reciprocals of primes in (P,2P] is rational, and the difference of two such sums, when nonzero, has absolute value at least (2P)^(-2k): multiply the difference by the product of the at most 2k prime denominators. This denominator bound is exact.

It gives a frequency resolution scale (2P)^(2k). Raising the moment order to offset the loss in extracting a value at one fixed n simultaneously enlarges that resolution scale. I did not prove an off-diagonal spacing estimate strong enough to get uniform local control at the specified n. The averaged theorem in Section 5 avoids this issue by genuinely averaging over n; it cannot be substituted into an EVERY-n claim.

### 6.5 Endpoint summation obstruction: not retried

    primes.push(p);
    for (let k = p * p; k <= limit; k += p) composite[k] = 1;
  }
  return primes;
