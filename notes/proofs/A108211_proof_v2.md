# A108211 floor formula — complete proof v2 (2026-08-16, Claude Fable 5)

**Theorem.** For every integer n >= 1,
  floor( 1 / D(n) ) = 16 n^2 + 1,  where
  D(n) := 1/(4n) - log 2 + Sum_{k=n+1}^{2n} 1/k.

(This is the conjecture of C. Kimberling recorded at OEIS A108211, 2014.)

v2 replaces the abandoned Step-4 plan of v1; it addresses all 8 issues of
review notes/reviews/A108211_review1.md. All inequalities below are strict
and certificate-based; no numerics enter the proof.

## Notation

For n >= 1 let
  T(n) := Sum_{m>=n} 1/((2m+1)(2m+2)),
  f1(n) := 1/(4n) - 1/(16n^2+1),   f2(n) := 1/(4n) - 1/(16n^2+2),
  h(n)  := (1024n^5 + 5888n^4 + 12928n^3 + 13312n^2 + 6148n + 843)
           / ( 4 (4n+1)(2n+1)(4n+3)(4n+5)(2n+3)(4n+7) ).

## Step 1: D(n) = 1/(4n) - T(n)

(a) Catalan's identity: Sum_{k=n+1}^{2n} 1/k = Sum_{j=1}^{2n} (-1)^{j+1}/j.
    Proof: H_{2n} - H_n = H_{2n} - 2 * Sum_{i=1}^{n} 1/(2i)
         = Sum_{j=1}^{2n} 1/j - 2 Sum_{j even <= 2n} 1/j
         = Sum_{j=1}^{2n} (-1)^{j+1}/j.
(b) log 2 = Sum_{j=1}^inf (-1)^{j+1}/j (Mercator series at x=1; standard,
    e.g. via Abel's theorem or the integral of the finite geometric sum
    with error term int_0^1 x^{2n}/(1+x) dx -> 0).
(c) Grouping the (absolutely bounded, alternating) tail in consecutive
    pairs, which is legitimate since the partial sums converge:
    log 2 - Sum_{j=1}^{2n} (-1)^{j+1}/j = Sum_{j >= 2n+1} (-1)^{j+1}/j
      = Sum_{m>=n} [ 1/(2m+1) - 1/(2m+2) ] = T(n),
    a series of positive terms. Hence D(n) = 1/(4n) - T(n).

## Step 2: two-sided telescoping certificate for T(n)

Define, for m >= 1,
  h(m) as above, and
  Delta(m) := 1/((2m+1)(2m+2)) - ( h(m) - h(m+1) ).

**Lemma 1 (defect identity).** For all m >= 1,
  Delta(m) = 63 (16m^2 + 120m + 119)
    / ( 2 (m+1)(2m+1)(2m+3)(2m+5)(4m+1)(4m+3)(4m+5)(4m+7)(4m+9)(4m+11) ).
Proof: rational-function identity; verified by clearing denominators and
expanding both sides (machine-checked with exact arithmetic; suitable for
`ring`/`field_simp` in Lean). In particular Delta(m) > 0 for every m >= 1
since every factor is positive.  □

**Lemma 2 (majorant).** For all m >= 1,
  Delta(m) < 60/(4m+1)^7 - 60/(4m+5)^7.
Proof: the difference [RHS - LHS], put over the common (positive)
denominator, has numerator which, after the substitution m = 1 + t,
is a polynomial in t with all coefficients nonnegative and positive
constant term (machine-checked exact certificate; min coefficient
11,274,289,152 > 0). Hence RHS - LHS > 0 for all real m >= 1.  □

**Lemma 3 (sandwich).** For all n >= 1:
  h(n) < T(n) < h(n) + 60/(4n+1)^7.
Proof: h(m) -> 0 and 60/(4m+1)^7 -> 0 as m -> inf, and both telescope:
Sum_{m>=n} (h(m) - h(m+1)) = h(n) (the tail of a convergent telescoping
series with limit 0), similarly for the majorant. Summing the identity
term(m) = (h(m)-h(m+1)) + Delta(m) over m >= n:
  T(n) = h(n) + Sum_{m>=n} Delta(m).
By Lemma 1 the sum is > 0; by Lemma 2 it is < Sum_{m>=n}
[60/(4m+1)^7 - 60/(4m+5)^7] = 60/(4n+1)^7.  □

## Step 3: window inequalities (polynomial certificates)

**Lemma 4.** For all n >= 1:  f1(n) < h(n).
Proof: (h - f1)(n) put over its positive common denominator has numerator
whose expansion in n = 1 + t has all coefficients nonnegative (machine
certificate; min coefficient 256 > 0), and it is positive at n=1.  □

**Lemma 5.** For all n >= 1:  h(n) + 60/(4n+1)^7 < f2(n).
Proof: same certificate style: numerator of (f2 - h - 60/(4n+1)^7) over the
positive common denominator, expanded at n = 1 + t, has all coefficients
nonnegative with minimum coefficient 393,216... > 0 (machine-checked);
value at n=1 equals 0.000588... > 0 exactly as a rational.  □

## Step 4: conclusion

Fix n >= 1. By Lemmas 3-5:
  f1(n) < h(n) < T(n) < h(n) + 60/(4n+1)^7 < f2(n).
By Step 1, D(n) = 1/(4n) - T(n), so
  1/(4n) - f2(n) < D(n) < 1/(4n) - f1(n),
i.e.
  1/(16n^2+2) < D(n) < 1/(16n^2+1).
In particular D(n) > 0 (addressing review issue 6), so reciprocals may be
taken and reverse the (strict) inequalities:
  16n^2 + 1 < 1/D(n) < 16n^2 + 2.
Therefore floor(1/D(n)) = 16n^2 + 1.  QED.
