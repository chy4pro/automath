# A114362 conjecture2 (Ordowski): tanh-sum asymptotic — proof draft v1 (2026-08-16, Claude Fable 5)

**Theorem.** Let t(n) = zeta(2n)/zeta(n)^2 for integer n >= 2. Then
  (1 - t(n))/(1 + t(n)) = 2^{-n} + 3^{-n} + 5^{-n} + 7^{-n} + O(11^{-n}).
Moreover (stronger, new): (1-t)/(1+t) - (2^{-n}+3^{-n}+5^{-n}+7^{-n}) ~ 11^{-n}.

**Status: DRAFT — pending adversarial review + numeric check + Lean feasibility.**

## Step 1: Euler product form

For s > 1: zeta(s) = Prod_p (1 - p^{-s})^{-1} (absolutely convergent).
Hence  t(n) = Prod_p (1-p^{-n})^2 / (1-p^{-2n}) = Prod_p (1-x_p)/(1+x_p),
where x_p := p^{-n} in (0,1). Absolutely convergent (Sum x_p < inf).

## Step 2: Möbius/tanh composition

Define a ⊕ b := (a+b)/(1+ab) for a,b in [0,1). Key exact identity: if
t = ((1-a)/(1+a)) * R  with R in (0,1], then
  (1-t)/(1+t) = a ⊕ (1-R)/(1+R).
(Direct algebra: both sides equal (1 - (1-a)R/(1+a)) / (1 + (1-a)R/(1+a))
 = ((1+a) - (1-a)R) / ((1+a) + (1-a)R); expand.)

Peel off p = 2,3,5,7:
  y := (1-t)/(1+t) = x_2 ⊕ ( x_3 ⊕ ( x_5 ⊕ ( x_7 ⊕ r ) ) ),
where r := (1 - R11)/(1 + R11), R11 := Prod_{p >= 11} (1-x_p)/(1+x_p).

## Step 3: bound the remainder r

1 - R11 <= Sum_{p>=11} (1 - (1-x_p)/(1+x_p)) = Sum_{p>=11} 2x_p/(1+x_p)
        <= 2 Sum_{p>=11} p^{-n} <= 2*11^{-n} * Sum_{k>=0} (11/(11+k-ish))...
Cleanly: Sum_{p>=11} p^{-n} <= 11^{-n} + Integral_{11}^inf u^{-n} du
        <= 11^{-n} (1 + 11/(n-1)) <= 2*11^{-n} for n >= 12; and for
2 <= n <= 11 use the trivial finite check of the final claimed inequality
numerically OR the bound Sum_{p>=11} p^{-n} <= zeta(n) - stuff... simplest:
Sum_{k>=11} k^{-n} <= 11^{-n} + int_{11}^{inf} u^{-n} du = 11^{-n}(1 + 11/(n-1))
 <= 12 * 11^{-n} for n >= 2. So  0 < r <= 1 - R11 <= 24 * 11^{-n}.
(r <= (1-R11)/(1+R11) <= 1-R11 since R11 <= 1... careful R11 in (0,1); fine.)

## Step 4: ⊕-corrections are O(12^{-n})

For a,b in [0, 1/2]:  0 <= (a+b) - a ⊕ b = ab(a+b)/(1+ab) <= ab(a+b) <= ab.
Unfold from inside out (all quantities <= 1/2 for n >= 2: x_2 = 2^{-n} <= 1/4,
sums stay < 1/2):
  w7 := x_7 ⊕ r        : |w7 - (x_7 + r)| <= x_7 * r <= 24 * 77^{-n}
  w5 := x_5 ⊕ w7       : |w5 - (x_5 + w7)| <= x_5 w7 <= 2 * 35^{-n}
  w3 := x_3 ⊕ w5       : |w3 - (x_3 + w5)| <= x_3 w5 <= 2 * 15^{-n}
  y  = x_2 ⊕ w3        : |y - (x_2 + w3)| <= x_2 w3 <= 2 * 6^{-n}  <-- !!

PROBLEM: the last bound 6^{-n} EXCEEDS 11^{-n}. The crude product bound is
too lossy at the outermost step. Fix: use the exact correction term
  (a+b) - a⊕b = ab(a+b)/(1+ab),
so the outer correction is x_2 * w3 * (x_2 + w3)/(1+x_2 w3)
  <= x_2 * w3 * (x_2 + w3) <= 2^{-n} * (3^{-n}+eps) * (2^{-n}+3^{-n}+eps)*(1+eps)
  <= (1+eps') * (2^{-n} * 3^{-n} * 2^{-n} + 2^{-n}*3^{-n}*3^{-n} + ...)
  = O(12^{-n}) + O(18^{-n}) = O(12^{-n}).  OK ✓ (12 > 11).
Similarly w3 correction: x_3 w5 (x_3+w5) = O(3^{-n}*5^{-n}*3^{-n}) = O(45^{-n}). ✓
w5: O(5^{-n}7^{-n}5^{-n}). ✓  w7: x_7 * r * (x_7+r) = O(7^{-n} 11^{-n} 7^{-n}). ✓

Total:  y = x_2 + x_3 + x_5 + x_7 + r + E,  |E| <= C * 12^{-n}
with explicit C (say C = 8 for n >= 2, TO VERIFY with careful constants).

## Step 5: conclude

|y - (2^{-n}+3^{-n}+5^{-n}+7^{-n})| <= r + |E| <= 24*11^{-n} + C*12^{-n}
  = O(11^{-n}).  QED (conjecture as stated).

Sharper: r >= (1-R11)/2 >= (1 - exp(-2*11^{-n}(1-o(1))))/2-ish; in fact
r = 11^{-n}(1+o(1)) since the p=11 factor dominates:
1-R11 = 2*11^{-n}(1+o(1)), r = (1-R11)/(1+R11) with R11 -> 1, so
r = 11^{-n}(1+o(1)). Hence y - Sum_{p<=7} p^{-n} = 11^{-n} (1 + o(1)):
the error constant is exactly 1. (Bonus theorem, stronger than conjecture.)
