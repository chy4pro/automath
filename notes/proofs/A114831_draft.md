# A114831: ratio limit sqrt(3) — proof draft v1 (2026-08-16, Claude Fable 5)

**Theorem.** Define a(1)=1, a(2)=2,
a(n) = a(n-1) + floor( 2 a(n-1) a(n-2) / (a(n-1) + a(n-2)) )  for n >= 3.
Then a(n+1)/a(n) -> sqrt(3) as n -> infinity.

**Status: DRAFT — pending adversarial review; numerics consistent
(a15/a14 = 1895/1094 = 1.73217..., sqrt3 = 1.73205...).**

## Step 0: monotonicity and growth

By induction: a(n) >= a(n-1) >= 1 for all n >= 2.
Harmonic mean fact: for integers A >= B >= 1, HM = 2AB/(A+B) in [B, A],
since 2A/(A+B) >= 1 and 2B/(A+B) <= 1. Hence floor(HM) >= B (as B is an
integer <= HM). Therefore
  a(n+1) >= a(n) + a(n-1)                                     (Fib bound)
so a(n) >= F(n) (Fibonacci), in particular a(n) -> infinity geometrically
(a(n) >= 1.6^{n-4} say, for n >= 6; crude bound suffices).
Also a(n+1) <= a(n) + a(n) = 2a(n) (HM <= max), so r_n := a(n+1)/a(n) in [1,2].

## Step 1: exact ratio recursion with floor error

2 a(n) a(n-1) / (a(n)+a(n-1)) = 2 a(n) / (1 + r_{n-1}') where
r'_{n-1} = a(n)/a(n-1) = r_{n-1}. Writing delta_n in [0,1) for the floor
defect:
  a(n+1) = a(n) + 2 a(n) / (1 + r_{n-1})^{-1}... [CLEAN FORM:]
  a(n+1) = a(n) + 2 a(n-1) a(n) / (a(n)+a(n-1)) - delta_n,
  r_n = a(n+1)/a(n) = 1 + 2/(1 + r_{n-1}) - delta_n / a(n)
      = phi(r_{n-1}) - delta_n / a(n),
where  phi(r) := 1 + 2/(1+r) = (3+r)/(1+r),  delta_n in [0,1).

## Step 2: invariant interval

phi is decreasing on [1,2]; phi(1) = 2, phi(2) = 5/3. So phi([1,2]) =
[5/3, 2] ⊂ [1,2], and with perturbation -delta_n/a(n) in (-1/a(n), 0]:
  r_n in [5/3 - 1/a(n), 2].
For n >= 6, a(n) >= 14 so r_n in [5/3 - 1/14, 2] ⊂ [1.59, 2] =: I.
(Direct check of small cases: r_2 = 2/... indices: r_2 = a3/a2 = 3/2,
r_3 = 5/3, r_4 = 8/5, r_5 = 14/8 = 7/4, all in [1.5, 2].)

## Step 3: contraction

For r in I = [1.59, 2]: |phi'(r)| = 2/(1+r)^2 <= 2/(2.59)^2 = 0.2982 =: q < 1.
sqrt(3) in I (1.732). phi(sqrt3) = sqrt3 (fixed point: r^2 = 3).
By the mean value theorem, for r in I:
  |phi(r) - sqrt3| <= q |r - sqrt3|.
Hence with eps_n := |r_n - sqrt3|:
  eps_n <= q * eps_{n-1} + 1/a(n)      for n >= 6.

## Step 4: conclusion

a(n) >= F(n) grows geometrically with ratio >= 1.6 > 1 eventually, and
q < 1, so by the standard perturbed-contraction estimate
  eps_n <= q^{n-6} eps_6 + Sum_{k=7}^{n} q^{n-k} / a(k) -> 0
(the sum is a convolution of two geometric null sequences; split at k = n/2:
head <= q^{n/2} * Sum 1/a(k) <= C q^{n/2}, tail <= max_{k>n/2} 1/a(k) * 1/(1-q)
<= C' 1.6^{-n/2}). Hence r_n -> sqrt3. QED.
