# AI 解决猜想案例情报体系（用户指令 2026-08-16 建立）

## 目的
1. 持续收录全网"AI 解决数学猜想/开放问题"案例（GitHub、arXiv、X.com、自媒体、新闻、Zulip/论坛）
2. 从案例提炼可复用的方法与选题信号，反哺 methodology
3. **未命中反思协议**：著名/有价值猜想被纯 AI 解决，而本项目既未收录情报也未尝试攻击
   → 必须在 retrospectives.md 写反思条目，诊断维度（逐条过，不许跳）：
   ① 情报源盲区 ② 选题过滤误杀 ③ 能力误判 ④ 动作太慢
   ⑤ **prompt 缺陷**（用户指令 08-16 增设）：给 agent/模型的提示词是否是问题根源——
      锚定错误来源、缺少时效性/多源要求、包含未经验证的"事实"、目标写歪、
      约束太松（放跳）或太紧（误杀）、缺少 T8 坚持条款等；
      反思时必须回读当时的实际 prompt（prompts/ 目录有版本留痕）做逐句审计，
      修正落到具体模板文件而不只是"下次注意"

## 文件
- cases.md — 案例数据库（追加式；字段：日期/问题/名气级/系统/方法/验证方式/来源URL/对我们的启示）
- scan_log.md — 每次扫描的时间、渠道覆盖、新增条数
- retrospectives.md — 未命中反思录

## 执行
- 扫描主力 = 免费网页模型（ChatGPT 网页自带搜索 / Qwen 网页），浏览器 agent 驾驶，零额度
- 补充 = Claude sonnet agent（WebSearch）用于网页模型覆盖不到的角度（首次全量扫描、X.com 专项）
- 节律：并入永续循环，每工作日 ≥1 次增量扫描；每次扫描后做"未命中比对"
