TITLE: [Misformalization] OEIS/100434: sign error in `b` makes all three conjectures refutable at n = 0; corrected identities are provable (Lean proof available)

### Describe the misformalization

`FormalConjectures/OEIS/100434.lean` defines
```lean
def b (n : ℕ) : ℤ :=
  if n % 2 = 0 then c (n + 1)
  else c (n - 1)
```
and records Dement's three conjectured identities `c n + d n = b n`,
`e n + f n = b n`, `g n + a n = b n` as `research open`.

As written, all three are refutable at `n = 0` (by `decide`-level
computation): `c 0 + d 0 = 1 + 2 = 3` while `b 0 = c 1 = -3`.

This appears to be a transcription of a sign-sloppy OEIS comment taken
literally. Dement's comment describes `c` as "A001333, apart from signs"
throughout, and states the identities' meaning as: the sequences
(c+d) = (e+f) = (g+a) "all represent the sequence c with even- and
odd-indexed terms reversed". The intended `b` (matching that description,
the numerics, and the file's own proven lemma `a_even : a (2n) = -c (2n+1)`)
has a minus sign on the even branch:
```lean
def b (n : ℕ) : ℤ :=
  if n % 2 = 0 then - c (n + 1)
  else c (n - 1)
```
With this corrected `b`, all three identities hold (verified numerically
for n < 2000, and proven — see below).

Related: PR #4560 ("Add OEIS A100434 disproof", closed) disproved the
literal reading; this issue proposes fixing the definition to the intended
statement instead, for which a full proof exists.

### Trivial proof/disproof

Refutation of the current statement at n = 0: `c 0 + d 0 = 3 ≠ -3 = b 0`
(both sides compute by `rfl`/`decide`).

### Suggested fix

Change `b`'s even branch to `- c (n + 1)` (as above), and — if desired —
reclassify the three theorems, since the corrected identities are provable
by `Nat.twoStepInduction` (all six sequences satisfy the same order-4
recurrence `x(n+4) = -6x(n+2) - x(n)`; the divisions in `e`/`f` are
discharged by parity lemmas `2 ∣ d(2k)`, `2 ∣ d(2k+1)`).

We have a complete, sorry-free Lean 4 proof of the three corrected
identities against current mathlib (axioms: propext, Classical.choice,
Quot.sound only), which we are happy to contribute as a PR if the proposed
fix is acceptable.
