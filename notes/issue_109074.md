TITLE: [Misformalization] OEIS/109074: `b` is A001764, not A005156, and the index shift is off — statement refutable at n = 1

### Describe the misformalization

`FormalConjectures/OEIS/109074.lean` formalizes the OEIS A109074 conjecture
"binomial(6n-2,2n) / (2*binomial(4n-1,2n)) = A005156(n+1)/A005156(n)".

Two independent problems:

1. **Wrong sequence.** The file defines
   ```lean
   def b (n : ℕ) : ℕ :=
     let num : ℕ := (3 * n).choose n
     let den : ℕ := 2 * n + 1
     num / den
   ```
   This is `C(3n, n)/(2n+1)`, i.e. OEIS **A001764** (ternary trees:
   1, 1, 3, 12, 55, 273, ...), not **A005156** (vertically symmetric
   alternating sign matrices: 1, 1, 3, 26, 646, 45885, ...). The two agree
   up to n = 2 and diverge at n = 3 (12 vs 26).

2. **Wrong shift.** Even with the correct A005156, the relation matching
   the numerics is `frac n = A005156(n) / A005156(n-1)`, not
   `A005156(n+1) / A005156(n)`:
   frac 2 = 3 = A(2)/A(1), frac 3 = 26/3 = A(3)/A(2), frac 4 = 323/13 = A(4)/A(3).

### Trivial proof/disproof

The formalized statement is refutable at `n = 1` by computation:
`frac 1 = C(4,2) / (2 * C(3,2)) = 6/6 = 1`, while
`b 2 / b 1 = (C(6,2)/5) / (C(3,1)/3) = 3 / 1 = 3`, and `1 ≠ 3`.
(A `decide`/`norm_num` disproof of the ∀-statement's `n = 1` instance goes
through directly on the file's definitions.)

### Suggested fix

Define A005156 by the Robbins–Kuperberg product formula (proved by
Kuperberg, so a valid closed form for the entry), e.g.
`A005156 n = ∏ k ∈ Finset.Icc 1 n, ((6k-2)! * (2k-1)!) / ((4k-1)! * (4k-2)!)`
(with the standard 1/2^k normalization folded in as in the OEIS Maple
code), and state the conjecture as
`frac n = A005156 n / A005156 (n-1)` for `n ≥ 1`.

Remark: with the product-formula definition the corrected statement reduces
to a finite factorial identity
`frac n = (6n-2)! (2n-1)! / (2 * (4n-1)! (4n-2)!)`,
so the mathematical content of the OEIS conjecture is precisely Kuperberg's
theorem; the entry may deserve a category other than `research open` after
the fix.
