# 030 Is 2√2/3 optimal for the weighted Erdős–Turán method? Prove kernel optimality or find a better kernel
priority: high · parallel: yes · report: /work/problems/erdos30/KERNEL_OPTIMALITY.md
Context (for the ROUTE sub-agents only): /work/problems/erdos30/SIDON_BOUND_PROOF.md (§2 kernel, §3–§4 half-line correction, §7 scalar limitation), /work/problems/erdos30/REFEREE_CLAUDE_B_20261002.md (kernel remarks), /work/problems/erdos30/KERNEL_SCAN_20261002.md (numerics: among tested families the ramp h(t) = 2(1−t) minimises √(ab) = 0.942809).
Question: over ALL admissible kernels, what is inf a(h)·b(h), where for h ∈ L²(R) with ∫h = 1, f = h * h~ (autocorrelation), a = f(0) = ||h||², and b = the boundary excess of the interval capacity (min energy of unit-mass measures on [0, L] equals 1/(L + b + o(1)))? Admissibility must be exactly what the Sidon step needs (state it: e.g. f ≥ 0 and Σ_{d≥1} f(d/T) ≤ T∫_0^∞ f + controlled error — is monotonicity of f needed, can h be signed, can h have unbounded support?). Either (A) prove inf = 8/9, attained at the ramp (a variational argument: Euler–Lagrange for the Wiener–Hopf/half-line problem, or a duality certificate), giving the theorem "the weighted Erdős–Turán energy method cannot beat 2√2/3"; or (B) exhibit an admissible kernel with a·b < 8/9, with a complete proof of the resulting Sidon bound coefficient √(ab) < 2√2/3 (then give explicit constants as far as possible).
Run in parallel: (i) ≥ 2 CLEAN-ROOM sub-agents (fresh context, no files, no web) given only the precise variational problem; (ii) one route sub-agent with the context above; (iii) one sub-agent checking the literature ONLY for whether this optimisation problem has been posed/solved (Hou–Zhao arXiv:2607.01169 Lemma 2.1 and its optimisation; Carter–Hunter–O'Bryant; Gupta–O'Bryant LM-rulers where √(8/9) also appears — is their extremal problem the same one?). Deliver: theorem with proof (A or B), or the sharpest partial statement (e.g. optimality within monotone h, or within compactly supported h ≥ 0) and what blocks the rest. No hype.
