# 039a NOTE from the coordinator for 039 Stage C (the functional J(f) = f(0)·∫|t|f / (∫f)² ) — heuristic input, verify before use
priority: note · no separate report

I looked at Stage C myself while you were busy. Unverified; treat as leads.

1. Restricted class f = h*h~ with h ≥ 0: Euler–Lagrange/KKT gives the half-cosine exactly. With Q = ∫h², D = ∬|x−y|h(x)h(y), ∫h = 1, stationarity on the support is D·h + Q·(|·|*h) = const; two derivatives give D h'' + 2Q h = 0, and the KKT inequality outside the support forces h to vanish at the endpoints. So h = (π/2) sin(πx) on [0,1], Q = π²/8, D = 1/4, J = π²/32 = 0.308425…, sonar coefficient 3(π²/36)^{1/3} ≈ 1.9494. (Convexity/uniqueness not checked.)

2. Full class (f ≥ 0, f̂ ≥ 0, no sign condition on h): π²/32 is probably NOT the infimum. Linearise J at the half-cosine optimum f₀ (scale: supp f₀ = [−1,1], ∫f₀ = 1, f₀(0) = π²/8, m₁ = 1/4): dJ ∝ ⟨g, |t| − 1/2 + (2/π²)δ₀⟩. An LP-dual certificate would need |t| − 1/2 + (2/π²)δ₀ = Φ + W with Φ̂ ≥ 0 supported on the zeros of f̂₀ (ξ = k/2, k odd, |k| ≥ 3) and W ≥ 0 vanishing on (−1,1). Complementary slackness determines Φ uniquely: Φ = (triangle wave |t| − 1/2, period 2) + (2/π²)·Σₙ(−1)ⁿδₙ, whose Fourier coefficients are (2/π²)(1 − 1/k²) at odd k — zero at k = ±1, positive for |k| ≥ 3, as required. But then W = S(t) − (2/π²)Σ_{n≠0}(−1)ⁿδₙ with S ≥ 0 continuous: W has **negative atoms at t = ±2, ±4, …**. So the certificate fails, and a descent direction should exist: smooth narrow bumps at t = ±2 plus a compensating signed piece inside (−1,1) that cancels ĝ(k/2) for odd |k| ≥ 3 (bumps must be smooth enough that ĝ/f̂₀ stays bounded; f̂₀ decays like ξ⁻⁴).
   Numerics (LP on piecewise-linear f, positivity of the trigonometric polynomial on a θ-grid, scipy/HiGHS, a few seconds): unrepaired optimum ≈ 0.30839–0.30842 for 120–240 nodes, with a small tail beyond the half-cosine support; after repairing grid infeasibility the value is back above π²/32. So the true gain, if any, is below ~1e-4 — it would move the sonar coefficient in the fourth decimal at most.

3. Suggested shape for the theorem: prove the sonar bound with the half-cosine kernel (coefficient 3(π²/36)^{1/3}) if its lattice-sum errors are manageable, otherwise with the triangle (coefficient 2) and state the half-cosine value as a remark with proof sketch; describe the barrier honestly: trivial floor 3(2/9)^{1/3} ≈ 1.817 (from a·m₁ ≥ 1/4), optimum within h ≥ 0 exactly π²/32, exact infimum over the full class open (my item 2). If you can settle the full-class infimum, good, but it is not worth many hours.
