T1 — Erdős #156. A Sidon set A ⊆ {1..N} (all sums a+b, a ≤ b, distinct) is maximal if no element of {1..N} can be added keeping it Sidon. s(N) = minimum size of a maximal Sidon subset. Target: s(N) ≪ N^{1/3}, or ≪ N^{1/3}(log N)^{θ} with θ < 1/3 (explicit construction with correlated coverage, algebraic sets in Z_{q²+q+1} or Z_{q²−1} lifted to an interval, cover-and-repair schemes). Seeds: (a) algebraic/modular construction + lifting; (b) random construction with a second-moment/Janson-type blocking argument instead of the union bound.

T2 — Erdős #1082. n points in the plane, no three collinear; M = max over points p of the number of distinct distances from p. Known: M ≥ ⌈n/3⌉ (isosceles-triangle double count: at most 2 apexes per base since bisectors contain ≤ 2 points). Target: M ≥ (1/3 + δ)n − O(1) with explicit δ > 0. Seeds: (a) quantify that "almost every base has exactly 2 apexes" and "almost every distance class around every point has size 3" cannot both hold up to o(n²) (incidence/kite structure, concyclicity); (b) weighted double counting with class-size-dependent weights plus a second-moment argument.

T3 — Erdős #86. π₄ = lim ex(Q_n, C₄)/(n 2^{n−1}) for subgraphs of the hypercube without 4-cycles; conjecture 1/2; known π₄ ≤ 0.60318 (flag-algebra SDP over coloured 4-cubes, 2012) and elementary 0.6068 (Chung 1992). Target: a human-readable proof of π₄ ≤ c with c < 0.60318 (e.g. an exact structural lemma about near-extremal Q₄/Q₅ configurations combined with averaging; ex(Q₃,C₄)=9, ex(Q₄,C₄)=24, ex(Q₅,C₄)=56).
