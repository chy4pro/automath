# Independent solve task (group theory)

This is a research-style group theory problem. Solve it and give a rigorous
proof. Do not search the internet. Do not read any files in this workspace
outside this task file.

If you cannot find a complete solution, you must NOT fabricate one. Present
only partial results you can rigorously prove (e.g., the result for

**Problem.** For integers m >= n >= 2, let
  Γ_{m,n} = { (σ, τ) ∈ S_m × S_n : sgn(σ) = sgn(τ) },
the index-2 subgroup of S_m × S_n consisting of pairs of equal parity.
It is known that Γ_{2,2} ≅ C_2 has rank 1, and Γ_{3,3}, Γ_{4,3}, Γ_{4,4}
have rank 3 (they are not 2-generated).

Prove: for all m >= n >= 2 with (m, n) ∉ {(2,2), (3,3), (4,3), (4,4)},
the group Γ_{m,n} is generated by two elements. Exhibit explicit generators.

Suggested angles (optional): Γ contains A_m × A_n as an index-2 subgroup;
the projections of Γ onto S_m and S_n are surjective; subgroups of direct
products are constrained by Goursat's lemma, so a generating pair
((σ1,τ1),(σ2,τ2)) works iff the projections generate the factors and the
generated subgroup is not trapped in a proper Goursat subgroup — the
delicate case is m = n where diagonal-type subgroups exist. Treat small
cases (n ∈ {2,3,4}) with care; the exceptional list is exact.

Write your complete solution to notes/reviews/fernandes_codex_solve.md.
Include: the generating pair(s) as explicit permutations (cycle notation),
the full proof, and a clear statement of exactly which (m, n) your proof
covers. If you verify small cases computationally (you may use python3),
include the verification code and its output, and mark clearly which parts
of the argument rely on computation versus proof.
