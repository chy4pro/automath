For n ≥ 1 let g(n) be the least integer g such that for every set {a1 < … < an} of integers greater than 1 and every x ≥ 0, some g of the integers x+1, …, x+an have product divisible by a1⋯an. Erdős and Surányi (1959) proved g(3) = 4 and g(n) ≥ (2−o(1))n, and Erdős asked (offering $100) whether g(n) ≤ (2+o(1))n, or even g(n) ≤ 2n (Erdős Problem #708). To our knowledge no upper bound depending on n alone has been published. We prove g(n) ≤ n(⌈log2 2n⌉ + ⌈log2⌈log2 2n⌉⌉ + 2) for n ≥ 2, g(n) ≤ ⌈48 n √((81+ln n)/ln(81+ln n))⌉, and g(n) ≤ (2+o(1)) n √(ln n/ln ln n). We also show that the conjectured bound holds for long intervals: if an ≥ 8n3 then 2n integers always suffice, so Erdős's question is reduced to the range an < 8n3; more generally (v2), for every integer k ≥ 2, kn integers suffice whenever an ≤ kn or ank−1 ≥ (kn)k+1. All proofs are elementary and constructive. We also record g(4) ≥ 5 and g(5) ≥ 6 by exact computation.

v3. A conditional linear bound: a single inequality about additive functions on intervals (the "hinge inequality": for weights 0 ≤ zp ≤ 1 and w = Σ zp vp, Σk≤m(w(k)−2)+ ≤ Σb∈I(w(b)−1)+ for every interval I of length m) implies g(n) ≤ 18n, by linear-programming duality and rounding. The inequality is proved for a single prime and in an explicit large-parameter regime, has no counterexample among 2.1·106 tested instances, and three natural strengthenings of it are shown to be false with explicit certificates (windows of length up to 106 containing more integers free of small primes than [1,m], via dense admissible sets). It remains open.

v4. Counting certificates: the hinge inequality follows, by linear-programming duality, from the two-sided count ⌊m/d⌋ ≤ NI(d) ≤ ⌊m/d⌋+1 of multiples alone in every instance we could compute (fractional weights up to m = 200, 0/1 weights with all primes up to m = 1000); an explicit certificate family proves the 0/1 case for every m ≤ 107 (and, by the asymptotics, up to about 1042 but not beyond); and Theorem A: for 0/1 weights the hinge inequality holds for all m with the threshold 2 replaced by c*(m) ≤ 20 ln ln m, by an explicit elementary sieve lemma. The fractional case needed for the linear bound reduces to an explicit integer statement.

v5. g(n) = O(n ln ln n): for arbitrary weights the hinge inequality holds for every m with threshold cm = 1 + 149e·ln(1+ln m), by a weighted sieve lemma (random thinning, a k-th order two-term Bonferroni inequality, an exact dyadic encoding of fractional valuations, and the two-sided count of multiples in an interval). Through the linear-programming duality this gives g(n) ≤ (17 + 149e·ln(1+ln(8n3)))·n, the first bound linear up to a ln ln n factor; the constant is poor, and the conjectured 2n remains open.

v6. Improved constant: for arbitrary weights the hinge inequality holds for every m ≥ 3 with threshold 20 ln ln m (previously 1 + 149e·ln(1+ln m) ≈ 405 ln ln m), by replacing the dyadic levels with geometric levels of ratio 51/50 and a factorial inversion with arbitrary gain, so that the ln ln L baseline is paid once instead of at every level; the budget lemma is closed by a finite interval computation (80 bins) and an analytic tail. Consequence: g(n) ≤ (16 + 20 ln ln(8n3))·n for all n, which is below the √ bound of v1 for every n and below the log bound for n ≳ 1035. v9. The fractional case (new Section 12): writing the weight as prime-power atoms, the hinge inequality with threshold 65 holds whenever the atoms with modulus at most m/64 have mean at least 17/16 (dense branch: affine certificate plus a second-moment bound), so a linear bound g(n) ≤ 81n follows from a 'sparse core' statement about atom systems of mean below 17/16. We show that this statement cannot be proved from the two-sided interval counts alone: projective-plane configurations satisfy every such count constraint and beat every fixed threshold, so the arithmetic values of the counts ⌊m/d⌋ must be used (they exclude these configurations already at first order).
