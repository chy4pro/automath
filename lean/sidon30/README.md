# Sidon30 — Lean formalisation project for the Sidon second-order bound (Erdős #30)

Target: `|A| ≤ √N + (2√2/3)·N^{1/4} + 1` for every Sidon set `A ⊆ {1,…,N}`, `N ≥ 120^4`
(paper: https://doi.org/10.5281/zenodo.23103979). Status: pipeline set up; nothing proved here yet.
Lean `v4.34.0-rc1`, Mathlib `de5ce8a9`. Built by GitHub Actions (`.github/workflows/sidon30-lean.yml`);
no local build is required.
