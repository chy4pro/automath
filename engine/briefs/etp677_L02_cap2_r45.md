## Setting (all definitions; nothing else is needed)
Fix a prime power q; n = q^2+q+1. A BRANCH OBJECT is an n x n array T over {0..n-1}
("table", rows indexed by a, columns by t, entry a*t := T[a][t]) such that:
 (B1) every ROW is a permutation of {0..n-1};
 (B2) for every column t there is a value nu(t) attained exactly q+1 times; the set
      ell_t := {a : a*t = nu(t)} ("line"); all other values are attained at most once;
      exactly q values are absent (the set D_t);
 (B3) the n sets ell_t form a projective plane of order q on the point set {0..n-1};
 (B4) t -> nu(t) is a bijection (forced; use as given).
Left division a\v = the unique w with a*w = v.  Define
  Xi_t(x) := x\(t\x);   E(t,v) := #{x : Xi_t(x) = v};   N(t,v) := #{a : a*t = v};
  delta(v) := (Sum_t E(t,v)) - n;   g(c) := nu(c)\c;   b(v) := #{c : g(c) = v};
  Z(x) := the set of values missed by COLUMN x of the Xi-array (t -> Xi_t(x)).
A row r is PERFECT iff E(r,v) = N(r,v) for all v; i.e. the Xi-row r has value nu(r)
exactly q+1 times, misses exactly the q values of D_r, and has every other value once.

## FACT SHEET (all PROVED for branch objects; cite by name)
ARRAY-LEVEL facts (true of the Xi-array as a combinatorial object):
 (F-pair)    distinct Xi-rows t,t' agree in EXACTLY one cell: if the line through t,t'
             is ell_c, the agreement is at position nu(c) with value g(c).
 (F-skel)    Xi_t(nu(c)) = g(c) for every t in ell_c.
 (F-vert)    for every position x the fibre sizes of t -> Xi_t(x) are {q+1 once, 1 x q^2,
             0 x q}; the big fibre is ell_{nu^{-1}(x)} with value g(nu^{-1}(x)); |Z(x)| = q.
 (F-deficit) delta(v) = q*b(v) - m(v), m(v) := #{x : v in Z(x)}.  Sum_v delta(v) = 0.
 (F-bcap)    delta(v) >= b(v)(q+1) - n; so delta(v) <= 0 forces b(v) <= q.
 (F-sigma)   sigma(v) := #{x : the Xi-column x carries v exactly once}
             = n - (q+1) b(v) + delta(v).
 (F-hbound)  for a perfect row p with w = nu(p) and h_p(w) := #{c : p in ell_c, g(c) = w}:
             h_p(w) >= (q+1) b(w) - q^2 - delta(w)   (i.e. q+1-h_p(w) <= sigma(w)).
 (F-budget)  for any set P of perfect rows and any value w:
             Sum_{c: g(c)=w} |P ∩ ell_c| + S_w(P) = |P| - #{r in P : w in D_r}
             + q*[w in nu(P)], with S_w(P) >= 0 the single-column hits of w by P.
COUPLING facts (these encode that the Xi-array comes from a TABLE — see the WARNING):
 (F-fusion)  x * Xi_t(x) = t\x for all t,x.  Hence for fixed t the map x -> x*Xi_t(x) is
             a BIJECTION, and x -> x*v is INJECTIVE on Xi_t^{-1}(v) for every v.
 (F-loc)     x in ell_v AND Xi_t(x) = v  <=>  x = t*nu(v).  Hence |Xi_t^{-1}(v) ∩ ell_v| <= 1.
 (F-ZD)      v in Z(x)  <=>  x in D_{x*v}.   Equivalently D_c = {x : x\c in Z(x)}, and
             C_x := {c : x in D_c} = {x*v : v in Z(x)}, |C_x| = q.
 (F-Tcount)  T_v := {t : Xi_t(x) = v for some x in ell_v} = {t : t*nu(v) in ell_v}, and
             |T_v| = (q+1) + q*[nu(nu(v)) in ell_v] - |ell_v ∩ D_{nu(v)}|.
 (F-perfD)   for a perfect row r, the values missed by Xi-row r are exactly D_r (the values
             absent from table column r), so D_r is readable from the array.

## WARNING (this decides what counts as a proof)
The ARRAY-LEVEL facts alone are SATISFIABLE by arrays with q+1 perfect rows AND delta == 0
(explicit q=2 phantoms exist).  Therefore any valid proof of the target MUST make
essential use of at least one COUPLING fact.  A derivation that uses only array-level
facts is automatically wrong somewhere; check your own proof against this.

## CALIBRATION (measured on every stored real object; do not contradict)

  tables with TWO perfect rows and delta == 0 exist at q=2, q=3; ONE perfect row with

- (F-hbound)'s consequences (b = q regime) are already banked; do not re-derive them.
