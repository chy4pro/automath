# PART 1 — DEFINITIONS

Graphs are finite, simple, undirected, connected.

* **C4-free**: no two distinct vertices have two or more common neighbours. (Equivalently: no
  4-cycle as a subgraph — chords are irrelevant.) **Triangles are allowed.**
* `N(v)` = open neighbourhood; `d(v)` = degree; `t(v)` = number of triangles containing `v`.
* `a(v) := α(G[N(v)])`, the independence number of the subgraph induced on `N(v)`.
* `l(G) := (1/n) Σ_v a(v)` where `n = |V(G)|`; `μ(G) := min_v a(v)`.
* `path(G)` := the number of **vertices** of a longest **induced** path. An induced `P_k` is a
  chordless path on `k` vertices. **"No induced P7" means exactly `path(G) ≤ 6`.**
* A geodesic is always induced, so `path(G) ≥ diam(G) + 1`.

**Fact F1 (proved, use as a black box).** C4-freeness makes `G[N(v)]` a matching plus isolated
vertices. Hence `a(v) = d(v) − t(v)`, and `G[N(v)]` has exactly `a(v)` components, each a single
vertex or a single edge.
*Why: if `x ~ y ~ z` inside `N(v)` then `v–x–y–z–v` is a 4-cycle.*

**Fact F2 (proved, use as a black box).** Let `Z = (z_0,…,z_5)` be an induced 6-cycle in a
C4-free graph and let `w ∉ Z`. Then `|N(w) ∩ Z| ≤ 2`, and **cyclic distance 2 is impossible**: if
`w ~ z_i` and `w ~ z_{i+2}` then `z_i` and `z_{i+2}` have the two common neighbours `z_{i+1}` and
`w`, a C4. So a 2-element trace is **consecutive** (cyclic distance 1) or **antipodal**
(cyclic distance 3), and `|N(w) ∩ Z| = 3` is impossible because every 3-subset of a hexagon
contains a pair at cyclic distance 2.

**Fact F3 (proved — and this is the fact the brief asks you to replace).** If `G` additionally
has **no induced P6**, the consecutive case dies too: if `N(w) ∩ Z = {z_0, z_1}` exactly, then
`(w, z_0, z_5, z_4, z_3, z_2)` is an induced P6. **Under no-P6, `W = ∅`. This is Lemma G32.**
