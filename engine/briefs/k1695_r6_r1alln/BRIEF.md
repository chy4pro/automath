# K6-R1ALLN — the rank-one stratum of Kourovka 16.95 for EVERY n, by hand (Pro seat; sandbox allowed; web only for literature)
Setting: F any field, A = I + uwᵀ ∈ GL(n,F) (1 + wᵀu ≠ 0), P_σ e_j = e_{σ(j)}, AP_σ = P_σ + u w_σᵀ with (w_σ)_j = w_{σ(j)}. B is cyclic iff for every μ in the algebraic closure rank(B − μI) ≥ n − 1. A rank-one update lowers rank by at most one, so AP_σ is non-cyclic iff for some eigenvalue r of P_σ (a root of unity whose order divides a cycle length of σ) rank(P_σ − rI + u w_σᵀ) ≤ n − 2, i.e. (Lemma T, proved): for a simple eigenvalue r with kernel vectors p, q: qᵀu = 0, w_σᵀp = 0 and 1 + w_σᵀ(P_σ − rI)⁺u = 0; for an eigenvalue of geometric multiplicity 2: u ∈ col(P_σ − rI) or w_σ ∈ row(P_σ − rI); multiplicity ≥ 3: always bad.
Known: n ≤ 3 proved for all A (Lean); for n = 4 the rank-one stratum is certified by Gröbner bases in characteristic 0 and all primes < 10⁴ but has no hand proof; for n-cycles σ every eigenvalue is simple (the n-th roots of unity, with multiplicities only in characteristic p | n), and the kernel vectors are Fourier vectors along the cycle, so "σ bad at r" reads: û(r̄) = 0 and ŵ_σ(r) = 0 (two Fourier coefficients along the cycle) plus one scalar equation. There are (n−1)! n-cycles.
Task: PROVE that for every n and every field some AP_σ is cyclic when A = I + uwᵀ — or find the first n where it fails (a counterexample would refute 16.95 itself; verify it exactly over the relevant finite field before reporting; disclosure: report fully, do not interpret). Suggested strategy: count, for the (n−1)! n-cycles, how many can be bad — each bad n-cycle at root r kills a pair of Fourier coefficients of u and of a permuted w; show that the total number of killed coefficients across cycles exceeds what a nonzero u and w with 1 + wᵀu ≠ 0 can afford (a dimension/incidence count over the cyclic orderings), handling characteristic p | n separately (multiple eigenvalue 1 for the n-cycle in characteristic p | n). If the n-cycles alone do not suffice, include (n−1)-cycles times a fixed point. Partial credit: n = 4 (closing the hand-proof gap of our chain), n = 5, all n in characteristic 0. Statuses PROVED/CONJECTURED/COMPUTED/FAILED per claim; ship exact verifiers for any finite claim.

NEW EVIDENCE (added 08-30, registry §R6.113) — a sharper, purely algebraic target. Deflation criterion (Lean-proved for every n): with v_i = 1 and R = A with row i deleted, columns c_i = x (the other coordinates of u) and c_k = e_k + y_k x (k ≠ i), for a column j and an ordering τ of the other n−1 columns let M = [c_τ(1) … c_τ(n−1)] and D_{j,τ} = det[c_j, M c_j, …, M^{n−2} c_j]; D_{j,τ} ≠ 0 ⟹ e_i is a cyclic vector of A P_σ (σ(i) = j, σ ordering the rest as τ). Computation: the ideal J_n ⊂ ℤ[x, y] generated by ALL n·(n−1)! determinants is the UNIT ideal for n = 4 (over ℚ and every prime < 10⁴) and for n = 5 (over ℚ and p = 2, 3, 5, 7, 11, 13, 17, 19, 23; 74 of 120 determinants nonzero, degree ≤ 8; msolve 15–46 s). CONJECTURE J: J_n = (1) for every n ≥ 2 — equivalently, for every field and every (x, y) ∈ F^{n−1} × F^{n−1} some Krylov determinant D_{j,τ} is nonzero. Proving Conjecture J proves the rank-one stratum of 16.95 for every n. Suggested route: exhibit explicitly, for each (x, y), a pair (j, τ) with D_{j,τ} ≠ 0 (e.g. using a coordinate with x_k ≠ 0 and a τ that makes M "almost a cyclic shift", so that c_j, M c_j, … are triangular); or find a polynomial identity Σ_{j,τ} a_{j,τ} D_{j,τ} = 1. Deliverable: a complete proof of Conjecture J for all n, or a counterexample (a point (x, y) over some field where every D_{j,τ} vanishes — verify by exact arithmetic), or a proof for an infinite family of n with the obstruction stated.
