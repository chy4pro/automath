# COMPUTATIONAL SEARCH — layered line systems for Erdős #709 (exact, reproducible; run code, report explicit data)

Definition. A t-layer line system is t finite sets S_1,…,S_t ⊂ ℤ (the layers) together with r "lines": integer arithmetic progressions b, b+d, …, b+(t−1)d with pairwise DISTINCT differences d ≥ 1 such that the j-th term lies in S_j for every j. (Loops-only model: one term per layer.) Its excess is r − (|S_1|+…+|S_t|). A system with positive excess yields, by an explicit CRT embedding, a set of r moduli and a window of t·max(A) consecutive integers without a full matching, hence f(r) ≥ t+1 for the Erdős–Surányi function f (erdosproblems.com/709). Known: a 3-layer system with 19 lines through 6+6+6 = 18 points exists (so f(19) ≥ 4); it is proved that no 3-layer failure exists for r ≤ 11 (so f(n) = 3 for 6 ≤ n ≤ 11). The smallest r with a positive-excess 3-layer system therefore lies in [12, 19].

Tasks (use Python; exact integers; print every construction in full so it can be re-verified):
T1. Find the minimum r admitting a 3-layer system with r lines and ≤ r − 1 points. Method: for each candidate r from 12 upward and each size triple (s_1,s_2,s_3) with s_1 s_2 ≥ r, s_2 s_3 ≥ r, s_1+s_2+s_3 ≤ r − 1, search layer sets inside [0, N) for N up to ~60–120 (use symmetry: translate S_1 to contain 0; note a line is determined by (x, z) ∈ S_1 × S_3 with x + z even and (x+z)/2 ∈ S_2, difference d = (z − x)/2; distinct d required). Use an exact method where feasible (ILP/SAT with variables for membership of each integer in each layer and for each pair (x,z) being a line; constraint: distinct differences ⇒ for each d at most one chosen pair with z − x = 2d; objective: maximise lines − points), or a well-designed local search with restarts; report what was searched exhaustively and what only heuristically.
T2. Report the best excess found for each r ≤ 19 and the explicit sets S_1, S_2, S_3 and the list of lines (x, y, z, d) for every record. For the 19-line system, try to shrink: fewer points or fewer lines with positive excess.
T3. Four layers: find any 4-layer system with positive excess (this would give f(r) ≥ 5); report the best excess found.
Output format: numbered results with status (EXHAUSTIVE for the stated N and sizes / HEURISTIC), explicit data, and the code you ran. No claims without the data.
