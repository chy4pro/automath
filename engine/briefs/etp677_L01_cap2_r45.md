## Setting (all definitions, nothing else needed)
Fix a prime power q; n = q^2+q+1. A BRANCH OBJECT is an n x n array T over {0..n-1}
("table", rows indexed by a, columns by t, entry a*t := T[a][t]) such that:
 (B1) every ROW is a permutation of {0..n-1};
 (B2) for every column t there is a value nu(t) attained exactly q+1 times; the set
      ell_t := {a : a*t = nu(t)} ("line"); all other values are attained at most once;
      exactly q values are absent (the set D_t);
 (B3) the 13 (resp. n) sets ell_t form a projective plane of order q on the point set
      {0..n-1}: every pair of distinct points lies in exactly one ell_t;
 (B4) t -> nu(t) is a bijection (this is forced, you may use it as given).
Left division a\v = the unique w with a*w = v.  Define
  Xi_t(x) := x\(t\x);   E(t,v) := #{x : Xi_t(x) = v};   N(t,v) := #{a : a*t = v};
  delta(v) := (Sum_t E(t,v)) - n.
A row r is PERFECT iff E(r,v) = N(r,v) for all v.
FACT SHEET (all previously proved for branch objects; cite by name):
 (F-fusion)  x * Xi_t(x) = t\x for all t,x.
 (F-pair)    two distinct rows of the Xi-array agree in EXACTLY one cell: if the unique
             line through points t,t' is ell_c, the agreement is at position nu(c) with
             value g(c) := nu(c)\c.
 (F-vert)    for every position x, the map t -> Xi_t(x) has fibre sizes exactly
             {q+1 once, 1 x q^2, 0 x q}; the big fibre is ell_{nu^{-1}(x)} with value
             g(nu^{-1}(x)).
 (F-deficit) delta(v) = q*b(v) - m(v) where b(v) = #{columns c with g(c) = v} and
             m(v) = #{positions x whose Xi-column misses v}.  Hence m(v) >= 0 forces
             b(v) >= 1 whenever delta(v) >= 1.
 (F-bcap)    delta(v) >= b(v)(q+1) - n; so delta(v) <= 1 implies b(v) <= q.
 (F-XM)      X(v) - M(v) = delta(v), X(v) := Sum_t max(E(t,v)-1, 0),
             M(v) := #{t : E(t,v) = 0}.  A perfect row r gives X(nu(r)) >= q.
 (F-skel)    Xi_t(nu(c)) = g(c) for every t in ell_c (no perfectness needed).
 (F-budget)  for any set P of perfect rows and any value w:
             Sum_{c: g(c)=w} |P ∩ ell_c| + S_w(P) = |P| - #{r in P : w in D_r}
             + q*[w in nu(P)], with S_w(P) >= 0 the single-column hits of w by P.
KNOWN DATA POINTS (do not contradict them): tables with THREE perfect rows and
delta-mass Sum_v |delta(v)| EXACTLY 4 exist at q=2 and q=3 (patterns (+2,-1,-1),
(+1,+1,-1,-1), (+1,+1,-2)); tables with TWO perfect rows and delta == 0 exist at
q=2 and q=3.  At q=2 it is EXHAUSTIVELY known that three perfect rows force
delta-mass >= 4.
