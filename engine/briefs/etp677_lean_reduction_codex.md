## Purpose
The R46 SAT instruments decide, for a fixed finite 677-magma B and fibre size m, whether a
"pair-indexed extension" of B by an m-element fibre exists in which E255 fails. To BANK an
UNSAT verdict as "no counterexample to 677→255 has quotient B with fibre size m" we need the
INTERPRETATION chain certified. Formalize the following, each as a Lean theorem with a
clean statement (no sorry, `#print axioms` at the end of each file):

L1  (Left translations are bijective.) For a finite type M with a binary operation `op`
    satisfying E677 `∀ x y, x = op y (op x (op (op y x) y))`, every left translation
    `fun z => op y z` is a bijection (surjective from the identity; injective by finiteness).
L2  (Quotient theorem, R7-C.) If `f : M → B` is a surjective magma homomorphism between finite
    E677 magmas, then all fibres `f ⁻¹' {b}` have the same cardinality. Proof route: the group
    generated by left translations is transitive because E677 gives `x = L_y (L_x (L_{L_y x} y))`;
    a left translation `L_{(y)}` maps the fibre over `b` bijectively onto the fibre over
    `f y * b` (use L1 in M and in B).
L3  (Pair-indexed form.) Given a finite E677 magma B, a type M, and a family of operations
    `c : B → B → M → M → M`, define on `B × M` the operation `(x,s) * (y,t) := (x*y, c x y s t)`.
    Prove: the product satisfies E677 iff for all `x y : B` and `s t : M`,
      `s = c y (y \ x) t (c x ((y*x)*y) s (c (y*x) y (c y x t s) t))`
    where `y \ x` denotes the unique `z` with `y * z = x` (exists and unique by L1 applied to B).
    State this as an `Iff`. (This is blueprint eq. (4) / registry (R9-A/eq4) with
    P1 = (y, y\x), P2 = (x, (y*x)*y), P3 = (y,x), P4 = (y*x, y).)
L4  (Defect criterion.) In any finite E677 magma N, E255 holds at `x` iff `∃ y, y * x = x`
    (blueprint Lemma 13.1(ii)/13.2(iii): the left unit candidate is `((x*x)*x)`). Then, in
    the product of L3 with B satisfying E255: E255 fails at `(a, σ)` iff for the unique
    `x_a` with `x_a * a = a` (unique by L1 in B), no `s` satisfies `c x_a a s σ = σ`.
L5  (Level transport.) If `φ : B ≃ B` is a magma automorphism of B and the family `c`
    satisfies eq.(4), then the transported family `c' x y := c (φ x) (φ y)` also satisfies
    eq.(4), and E255 fails at `(a,σ)` for `c'` iff it fails at `(φ a, σ)` for `c`. (This
    is the WLOG "defect level a = 1" step; state it for a general automorphism.)
L6  (Idempotent level.) If `a * a = a` in B then eq.(4) at `(a,a)` says exactly that
    `c a a` satisfies E677 on M; and E255 at `(a,σ)` in the product is E255 for `c a a` at σ.
