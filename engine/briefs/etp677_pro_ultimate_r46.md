## The statement
E677:  x = y*(x*((y*x)*y)).   E255:  ((xx)x)x = x.
OPEN (Equational Theories Project, "finite implication 677 → 255"): does every FINITE magma
satisfying E677 satisfy E255? Infinite counterexamples exist (greedy constructions), so any
proof must use finiteness; any counterexample must be finite. Either outcome is the prize.

## Facts you may use (all PROVED unless marked)
F1. In a finite E677 magma every left translation L_y is a bijection (E677 exhibits every x
    as a product y*(…)); write y\z for L_y^{-1}. KEY: (y*x)*y = x\(y\x). Right translations
    need not be bijective.
F2. Unary maps: S(x) = xx, W(x) = x\x, U(x) = (xx)x = x\W(x) [from E677 at (x,x)],
    P(x) = x\U(x), F(x) = x\P(x), H(x) = S(x)*U(x). F∘H = H∘F = id (finiteness).
    E255 at x ⟺ U(x)*x = x. Lemma L-A: u*x = x ⟹ x*u = W(x) and U(x) = u; so under E255
    Fix(L_u) = U^{-1}(u) and x*U(x) = W(x). W(x)*S(x) = U(x). No L_x-cycle through x of
    length 2, 3, 4 (E677), 5 (E677+E255); with E255, x idempotent ⟺ F(x) = x ⟺ U(x) = x.
F3. MONOGENIC REDUCTION: if E255 fails at x then it fails inside the submagma ⟨x⟩. So the
    statement ⟺ "every finite ONE-generated E677 magma satisfies E255 at its generator g".
    In cycle coordinates (c_i = L_g^i(g), period m ≥ 6): U(g) = c_{m−2} and E255 at g ⟺
    c_{m−3}*g = c_{m−4}.  Certified: no finite E677 magma of order ≤ 8 has a generating point
    failing E255 (SAT/DRAT); the community exhausted all E677 magmas of order ≤ 12.
F4. AMPLIFY: E(M) = {x : E255 at x}; E(M×N) = E(M)×E(N); so a counterexample A with

    uniform bound δ(M) ≥ |M|^{−o(1)} proves the statement.
F5. MODELS (all E677+E255): affine x*y = αx+βy+γ over F_p needs αβ(1+β²) = 1 and
    α + α²β² + β³ = 0 (e.g. F7: 4x+3y, 4x+y; F13; F31: 5x−4y+1, idempotent-free).
    SWITCHING: for ANY E677 magmas ⋆, ∘ on a set X, Z7 × X with (q,s)*(r,t) = (4q+r, s⋆t)
