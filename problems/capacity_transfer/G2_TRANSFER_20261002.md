## Item 1. Sonar sequences

**Definition (READ, EGRT 1992 p. 39).** "An n x m sonar sequence is an array of dots and blanks having n rows and exactly
one dot in each of its m columns, subject to the requirement that distinct pairs of dots determine distinct vectors."
Maximise m for given n. The scout's definition matches. Note the letter swap in later literature: Moreno-Games-Taylor,
Osorio et al., Trujillo, Jin-Kim-Chae-Song write "m x n sonar sequence" = function f: [1,n] -> [1,m] (m rows, n columns)
and study G(m) (or SS(m)) = max n.
Modular variant (READ, Osorio et al. 2014 Lemma 1.2; Ruiz-Trujillo-Caicedo arXiv 1311.1679): f: [1,n] -> Z_m with
distinct differences mod m; trivially G(mod m) <= m + 1, attained for primes (quadratic construction). It is a
different, already-tight problem, consistent with the scout's "no gain" remark.

## Item 2. Weak Sidon sets

**Definition (READ, BFR arXiv v2 §5).** A = {a_i} with a_i + a_j distinct for i < j; W(n) = max size in [n]. Same as
Kayll 2005, Ma-Tang 2026, Xu-Liang-Shao 2014.

**Record.** Balogh-Füredi-Roy, arXiv 2103.15850 (v1 2021-03-29, v2 2021-06-17), §5, **Theorem 5.1**: "There exists a
constant γ >= 0.0089 such that W(n) <= n^{1/2} + n^{1/4}(√3 − γ) + O(1)" (READ; the proof ends with "larger than
0.00896"). So the coefficient is <= 1.7232. Previous: Kayll, Discrete Math. 299 (2005) 141-144, W(n) <= n^{1/2} +
√3 n^{1/4} + O(1) (SECONDARY via BFR (5.1), which has the typo n^{1/4} for n^{1/2} in the leading term). Ruzsa 1993 is
cited by BFR as an alternative route to (5.1). Kayll's primary is NOT ACCESSIBLE (ScienceDirect CAPTCHA).

**Citation correction.** The scout attributes Theorem 5.1 to Amer. Math. Monthly 130 (2023) 437-445. The Monthly
abstract (READ) mentions only the Sidon bound 0.998, and the Crossref reference list of the Monthly version (20 refs,
READ) omits Kayll 2005 and Caicedo-Martos-Trujillo 2015, which the arXiv version needs for §5 and §6. Inference (not
verified from the journal text, which is paywalled): the weak-Sidon and t-thin sections exist only in the arXiv
versions. CHO nevertheless cite "[BFR23] (Theorem 6.2)" with the Monthly reference, so this is left open.

**Papers checked.** All citers of BFR (OpenAlex 10 + 2, Semantic Scholar 26) and of Kayll (Google Scholar 8) by
title/abstract; read: Ma-Tang arXiv 2602.23282v2 (Sidon subsets inside weak Sidon sets and (4,5)-sets; cites Kayll;
no W(n) bound); Xu-Liang-Shao, JCMCC 91 (2014) 107-113 (READ pp. 107-108: computes g(n) for n <= 172; asymptotics
only Ruzsa n^{1/2} + O(n^{1/4})); O'Bryant arXiv 2207.07800 (no weak Sidon); CHO arXiv 2310.20032 (no weak Sidon);
Hou-Zhao arXiv 2607.01169v3 (no weak Sidon; see "general idea" below); Ruzsa, JLMS (published 2026-09-24) survey
"Sidon sets from Erdős and Turán to yesterday" (READ, open access: restricts itself to the original problem; record
quoted is CHO 0.98183); arXiv abstract query "weak Sidon" (3 hits, none relevant). Not accessible: S. Roy 2023 UIUC
thesis (repository link failed).

**erdosproblems.com.** No problem on the size of weak Sidon sets in [N] was found. Related entries: #864 (at most one
exceptional sum; forum comment gives (√2 + o(1))N^{1/2}), #840 (quasi-Sidon), #757 (cites Ma-Tang [MaTa26] for
(4,5)-sets). None states a second-order weak-Sidon bound.

**Verdict: NO EARLIER MATCH FOUND (bounded).** The candidate √(8/3) = 1.63299 is below every located bound (1.7232).

## Item 3. g-thin Sidon sets (g-Golomb rulers)

**Definition (READ).** CHO §4: "|{(a,b) ∈ A^2 | a != b, a − b = d}| <= g for all d". BFR §6: |A ∩ (A + c)| <= t for
c != 0. Gupta-O'Bryant: at most g pairs with d = b − a. Same object as the scout's.

**Records.**

In size form the CHO bound has N^{1/4}-coefficient 1 − ε_g/2 on (gN)^{1/4} (for g = 2 and the arXiv ε this is about
0.9951). The scout's description of the record is accurate.

**Has the transfer of improved Sidon constants to g-thin sets been stated?** Hou-Zhao v3, closing section (READ): the
framework "suggests analogous programs for bounded-multiplicity difference problems ..., although such extensions
would require separate analytic input". This is a suggestion, not a stated result. CHO and BFR transfer their own
methods. erdosproblems #863 (READ) states only the leading order: "a routine adaptation of the Erdős-Turán bound for
Sidon sets proves |B| <= (√r + o(1))N^{1/2}". Gupta-O'Bryant arXiv 2605.14229 and Gupta arXiv 2607.07931 (READ: high-
multiplicity regime and modular constructions) give no fixed-g second-order bound. Bosio-Riblet-Tarr arXiv 2607.02728
(READ intro) discusses B_2[g] sums, not differences. Johnston-Tait-Timmons (B_k[g], sum version) is a different
problem.

**Verdict: NO EARLIER MATCH FOUND (bounded).** Caveat: the transfer N -> gN is routine for any scalar energy/kernel
proof. Hou-Zhao's own unrefereed 0.9435 would transfer the same way, though nobody has written it down. The novelty of
item 3 therefore rests entirely on the Sidon result R1 and should be presented as a corollary, not an independent
advance.

## Item 4. Difference triangle sets

**Definition (READ).** Chee-Colbourn 1997: an (n,k)-DTS is n blocks X_i = {a_i0 < ... < a_ik} (k + 1 marks), all
differences within blocks distinct; scope m = max element after normalisation; m(n,k) = min scope. Shearer 1999 uses
Kløve's (I,J) with J + 1 marks. Same as the scout's. Strict optical orthogonal codes are equivalent (Chu-Golomb 2003;
title READ).

**Record.** Kløve, IEEE IT 34 (1988) 355-361, Theorem 2, as quoted by Chee-Colbourn, IEEE IT 43 (1997) Theorem 1
(arXiv 0712.2553, READ): m(n,k) >= n(k^2 − 2k√k + (k + √k)/4) for all n, k. **SECONDARY**: the Kløve 1988 primary is NOT
ACCESSIBLE (abstract READ: "New lower and upper bounds"). Kløve, IEEE IT 35 (1989) 879-886, abstract (READ): "A lower
bound on the maximal element in any (I,J)-DTS is then given"; its form is NOT ACCESSIBLE. LP bounds (Lorentzen-Nilsen
1991; Shearer, EJC 6 (1999) R31, READ) are numerical, for small J, with closed forms only for J = 5, 6 (Remark 2, as quoted
by Ma-Yi).

**Papers checked.** Shehadeh-Kingsford-Kschischang arXiv 2502.19517v2 (READ, §II: "Improved lower bounds on m(n,k)
are provided by Kløve [1989]. Better lower bounds are provided by Lorentzen and Nilsen via linear programming ... further
improved by Shearer"; no asymptotic statement, no Sidon-bound transfer); Ma-Yi arXiv 2608.13739 (READ: "direct version
of Kløve's small-difference argument" for a different packing problem); Higher-order staircase codes arXiv 2312.13415
(Kløve cited only for constructions); Liu-Feng-Wang-Zhang arXiv 2510.20446 survey (READ: trivial bound only); Xu et al.
arXiv 2409.14409 and Xiu-Fan-Liang arXiv 1405.4535 (disjoint Golomb rulers: a different problem); 34 Google Scholar
citers of Kløve 1988 and the first 10 of Kløve 1989 by title. No paper connects BFR / O'Bryant / CHO / Hou-Zhao to DTS
lower bounds.

**Access gaps.** Kløve 1988 and 1989 full texts; Chen-Kløve, "Lower bounds on multiple difference sets", Discrete Math.
98 (1991) 9-21 (NOT ACCESSIBLE: ScienceDirect CAPTCHA; zbMATH review withheld); Chen-Kløve, Discrete Math. 148 (1996)
"Lower bounds on multiple distinct sum sets" (review: "improved lower bounds"); CRC Handbook DTS chapter.

**Verdict: NO EARLIER MATCH FOUND (bounded)** for any general lower bound with k^{3/2}-coefficient < 2. Moderate risk

## Item 5. Distinct-difference configurations, square grid, Manhattan diameter r

**Definition (READ, BEMP arXiv 0811.3832v2, 2009-10-08).** A DD(m,r) is m dots in the square grid with all difference
vectors distinct and pairwise Manhattan distance <= r.

**Record.** BEMP, IEEE IT 56 (2010) 1216-1229; arXiv v2 **Theorem 9**: "If a DD(m,r) exists, then m <= (1/√2)r +
(3/2^{4/3})r^{2/3} + O(r^{1/3})" (READ; 3/2^{4/3} = 1.19055). The proof uses Lee-sphere windows of radius l = α r^{2/3}
and the bound m^2 <= w(1 + m/a). The journal version's section list (READ, IEEE page) has "III. Upper Bounds on the
Number of Dots", so the theorem number in the journal may differ from arXiv v2; not verified.

**Papers checked.** Citers of BEMP: Google Scholar 23, IEEE 14, Semantic Scholar 18, all screened by title. Read:
Blackburn-Etzion-Martin-Paterson, "Distinct difference configurations: multihop paths ..." arXiv 0811.3896v2 (READ:
reuses "[1]: m <= (√π/2) r + O(r^{2/3})" for the Euclidean case; no improvement); Blackburn-Panoui-Paterson-Stinson,
"Honeycomb arrays" arXiv 0911.2384 (hexagonal grid); Blackburn-Smith-Stewart arXiv 2307.03627 (free groups); Etzion
arXiv 0911.1745 and 1102.2986, Drakakis arXiv 1102.5727 (no Manhattan bound). The brief's "Zhang-Ge" paper was not
located. Not accessible: L. Stewart, PhD thesis (Royal Holloway 2023; bot wall), Panoui 2012 thesis, Etzion 2024
chapter.

**Verdict: NO EARLIER MATCH FOUND (bounded).** No later bound on the r^{2/3} term was located. The candidate
3·2^{-4/3}(8/9)^{2/3} = 1.10064 is below 1.19055.

## The general idea: exact capacity constant / exact column marginal

* **Hou-Zhao arXiv 2607.01169v3** (READ). They use several kernels "each accompanied by boundary weights that
  compensate for endpoint effects" and derive k^2 <= (N + bH − 1)(1 + a(k−1)/H), giving coefficient √(ab). This is the same
  scalar a·b architecture as ours, with a numerically optimised discrete boundary vector. They do not identify a
  continuous capacity, the ramp kernel, the value 2/3, or the 8/9 barrier. Their extensions remark is quoted under item 3.
  Status of the idea "reduce the boundary loss by optimised boundary weights": **PARTIALLY KNOWN** (Hou-Zhao, preprint).
  The exact capacity constant and the barrier: no match found.
* **Exact column marginal in the Cauchy-Schwarz step** (sonar): no match found in EGRT, Osorio et al. 2014 (plain box
  energy), Trujillo 2023, BEMP, or any of the readable citers. Chen-Kløve 1996 and Robinson 1985 are unread (item 1).
* **O'Bryant / CHO** (READ): an exact identity (ETSSE) with slack terms S and V, not a capacity formulation. CHO extend
  it to g-thin sets only. Gupta-O'Bryant: the constant 2√2/3 = √(8/9) appears for LM rulers via a gap-counting
  argument, a different theorem (see `problems/erdos30/G2_FINAL_20261002.md` §2). O'Bryant's NYNTS talk (2026-10-01)
  abstract concerns infinite sets.
* **erdosproblems.com #30 forum** (re-read about 20:45 UTC): still 8 comments, identical to the G2_FINAL record. No
  comment on extensions, capacities or other problems.
* **wustep/maths** (default branch pushed 2026-09-27; sidon-second-term RESEARCH/ATTACK/PROBLEM and the 2026-08-27
  report READ): no weak-Sidon, g-thin, sonar, DTS, capacity or 8/9 content.
* **teorth/optimizationproblems README** (READ): constants 5a (Sidon size, 0.97633) and 5b only; no entries for weak
  Sidon, g-thin, sonar or DTS.
* **New Sidon-side item not in G2_FINAL:** Zenodo DOI 10.5281/zenodo.22212915 with GitHub repo
  antminers99/sidon-gamma-certificate (created 2026-08-31; README and CRITIQUE READ). It claims γ < 0.94285
  ("measured 0.9428376714931955") in Hou-Zhao's Lemma 2.1 class, describes itself as "numerical polish, not a new
  inequality", and says pushing below 0.94 in that frame failed. It is still above 2√2/3 = 0.9428090 and does not
  anticipate R1. It does replace 0.943006 as the smallest located same-scope external coefficient.
  The certificate was not run. The Zenodo API returned 403 at access time, so the record page itself was not read.
