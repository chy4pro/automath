## 0. Verdict (short)

**SUBSUMED, via a short reduction.** Theorem A is not stated word for word in any source I
read. It follows from a published, effective theorem, Langevin, *Acta Arith.* 39 (1981)
241–249, Corollaire 1 (8), plus a ~10-line elementary lemma (§3). The lemma sends each
prime p ≤ K with p ∤ n to a K-smooth term of the block. Langevin's bound on the number of
K-smooth terms then gives a contradiction. The same reduction gives the uniform-in-l form
and works for any K ≥ (1+ε) log n, so the constant 10 is not special. The planned
Baker/Matveev proof campaign (R1–R6) is not needed and should be killed. What seems to be
new is only the *observation* connecting these, which I found nowhere: ErSe67 calls it
open, erdosproblems.com still lists #889 as OPEN with 0 proof claims, and the FC variant
`v1_eq_1_finite` is still open. §6 lists what remains.

## 1. Target (exact)

v(n,k) = #{p prime : p | n+k, p ∤ n+i for all 0 ≤ i < k} = #{p | n+k : p > k} for k ≥ 1
(FC `Erdos889.v`, which matches the site). v_l(n) = sup_{k ≥ l} v(n,k) in ℕ∞.

* Theorem A: there is an explicit N0 such that every n ≥ N0 has some k with 1 ≤ k ≤ 10 log n and v(n,k) ≥ 2.
* Corollary A1: {n : v₁(n) = 1} is finite. This is FC `erdos_889.variants.v1_eq_1_finite` with answer True.
* Theorem A_l: for each fixed l ≥ 1 and n ≥ N(l), some k ∈ [l, C·l·log n] has v(n,k) ≥ 2.

## 3. The reduction (the key finding; same-vendor check only)

**Lemma.** Let n ≥ 1 and K ≥ 2. Assume v(n,k) ≤ 1 for every 1 ≤ k ≤ K. For each prime p ≤ K
with p ∤ n, let k₀(p) be the least k ≥ 1 with p | n+k. Then 1 ≤ k₀(p) ≤ p−1, P(n+k₀(p)) = p,
and p ↦ k₀(p) is injective. Hence
#{1 ≤ k ≤ K : P(n+k) ≤ K} ≥ π(K) − ω(n).

*Proof.* Since p ∤ n, we have k₀ ≤ p−1 < p. So p is a prime factor of n+k₀ exceeding k₀.
Because v(n,k₀) ≤ 1, p is the only such factor, and every other prime factor of n+k₀ is ≤ k₀ < p.
Therefore P(n+k₀) = p ≤ K. Injectivity holds because P(n+k₀(p)) = p recovers p. ∎

**Theorem A from Langevin 1981 Cor. 1 (8).** Take a = 1 and k = K = ⌊10 log n⌋. Then
log n/log K → ∞, so the hypothesis log n/log k ≥ r(ε) holds for large n. By (8), with
L = log n/(log K)², card Y ≤ (1+c+ε)π(K)·loglog L/log L = o(log n/loglog n). By the lemma,
card Y ≥ π(K) − ω(n) ≥ (10 − 1.3841 − o(1))·log n/loglog n, using ω(n) ≤ 1.3841 log n/loglog n
(Robin) and π(K) ~ K/log K. These conflict for n ≥ N0, and N0 is effective because C, c
and r(ε) are. Hence some k ≤ 10 log n has v(n,k) ≥ 2, and Corollary A1 follows.

* Any K ≥ (1+δ) log n works in place of 10 log n.
* **Theorem A_l** follows in the same way. Take primes l < p ≤ K with p ∤ ∏_{j<l}(n+j). The least k₀ ≥ l with p | n+k₀ then lies in [l, p−1], and the same injection applies. This gives ≥ π(K) − π(l) − l(1.3841+o(1)) log n/loglog n smooth terms, which (8) excludes for K = C·l·log n with C > 1.3841 and n ≥ N(l).

**Numerical sanity check (evidence only).** For every n < 3·10⁵, I checked whether some
k ≤ 10 log n has v(n,k) ≥ 2. Such a k exists for all n in that range except 28 values, the
largest being n = 330, which matches ErSe67's list. In all 28 cases the lemma's assertions
held: k₀ < p, P(n+k₀) = p, and the map is injective. The check was a stdlib Python script
kept in a scratch directory, not in the repo; it cost seconds of CPU.

**What I did not check.** I did not referee Langevin's proof; I rely on the published
statement, read from the scan. The reduction has had a same-vendor check only. My reading
of (8) is from the 1981 scan. The "log₂" notation (= loglog) is defined on p. 241.

## 4. Verdict and justification

**SUBSUMED (by reduction to published work).** The plan's headline result is an explicit N0
with some k ≤ 10 log n having v(n,k) ≥ 2 for n ≥ N0, hence finiteness of {n : v₁(n) = 1}.
That is a corollary of Langevin's 1981 effective bound on the number of k-smooth integers in
(n, n+k]. The link is a 10-line counting lemma that sends each prime p ≤ K not dividing n to
a distinct K-smooth term. RST I/II do not contain it: RST II's "≤ π(k)" is exactly
borderline and too weak. Langevin's o(π(k)) refinement suffices, as does, by Langevin's own
attribution, Tijdeman's 1977 derivation for n ≥ exp(k^{ε'}), which I did not read.
Erdős–Selfridge's 1967 "we have not even been able to prove" came before this Baker-method
work.

The skeptic's worry was that an expert might call it a routine RST/Tijdeman corollary. That
is confirmed, in a sharper form: it is a routine corollary of Langevin 1981. An independent
proof via Matveev (R1–R6) would add a new *proof*, not a new theorem. It would also be
harder to verify than the reduction.

## 5. Consequences for the #889 line (recommendations to the coordinator)

1. Kill the Baker/Matveev proof campaign (R1–R6) and the 10⁹ witness-certificate plan. Their purpose (proving Theorem A) is already met by a published result.

   * Get an independent referee check of the §3 lemma and of how Corollaire 1 (8) is applied. In particular check that the hypotheses of (1) hold with a = 1, and how r(ε) and the example constants depend on t₁…t₆.
   * Try again to get [Er98] p. 178, Guy B27 (3rd ed.) and the Shorey–Tijdeman 1986 book. One of them may already record this corollary, or record the problem as open after 1981.
   * Only then decide whether a short note is worth publishing. It would say that v₁(n) = 1 has only finitely many solutions, by Langevin 1981 plus the lemma, with an effective but astronomically large N0.
   * Per project rules, make no forum post or FC PR without the publication gates in OPERATIONS.
3. Lean. An unconditional formal proof would need Langevin's theorem, so it would be conditional (Langevin as a hypothesis), as with the plan's Matveev issue. The lemma itself is easy to formalise and could be formalised unconditionally.

## 6. What remains potentially new (and how much it is worth)

* **The observation or connection itself** is the main item. It seems unrecorded: ErSe67 calls it open, erdosproblems shows OPEN with 0 claims, FC `v1_eq_1_finite` is open, and Kitamura named lowercase v₁ as open on 2026-09-22. It is worth one short note, not a research paper.
* **An explicit numerical N0.**
  * Langevin's constants are effective and he gives example values, so "effective N0" is not new.
  * My rough, unverified estimate from his example constants puts N0 around exp(exp(2·10⁹)), driven by r(ε) = C·C^{(1+c)/ε} with C = e^{10⁶}, c = 2000.
  * The plan's Matveev route reportedly gives log N0 ≈ 1.1·10²⁰. That would be a real but minor quantitative improvement.
  * Neither bound reaches the conjectured largest exception, 330.
* **The k ≤ 10 log n range** is not new. Any (1+δ) log n follows from the reduction.
* **The uniform-in-l form** (level 2 of `general`) is not new. It follows from the same reduction (§3).
* **Untouched open parts:**
  * the main conjecture v₀(n) → ∞;
  * v₀(n) ≥ 3 eventually (by Luccioli's inequality this would give v₁ ≥ 2 again);
  * v_l(n) → ∞ at levels above 2;
  * the exact exception lists: 330 for v₁ and 80 for V₁. Kitamura proved V₁ finiteness without an explicit bound.
